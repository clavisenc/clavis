Use Clavis from the File Explorer right-click menu

The Windows installer adds Clavis to File Explorer's right-click menu, so you rarely need to open the app first. On Windows 11 it's under Show more options (or press Shift+F10).

What's in the menu

Right-click on…You can
Any file or folderEncrypt (a whole folder: Pro) · Encrypt to cloud folder Premium · Encrypt for someone… Premium
A file or a .enc fileSend with a password… (free, see Sharing)
A .enc fileOpen Pro · Decrypt · Verify · Send with a password… · Previous versions… Premium
A folderDecrypt (free) · Verify (free) · Add to Watch Folder Pro
Any file, .enc file or folderShred… (last in the menu; see Shred files)

Select several files and right-click once: Clavis handles them as one batch with a single confirmation.

Double-click

  • .enc — opens the file Pro.
  • .clavisid — adds that person to your contacts.
  • .clavisbackup — restores a vault backup.

Don't want the menu? Untick Settings → Explorer → Show Clavis in the right-click menu.
