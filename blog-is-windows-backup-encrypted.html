Is Windows Backup encrypted? What each backup protects

A backup saves you when a drive dies or a laptop is stolen. It is also a second copy of everything private, often on a USB drive in a drawer. Whether it's encrypted depends on which Windows backup made it. Here is what Microsoft says about each, what someone holding your backup could read, and three ways to make an encrypted backup.

Short answer: not with a password of your own. The Windows Backup app syncs your folders to OneDrive, where Microsoft encrypts each file at rest, but anyone who signs in to your Microsoft account sees them. File History and the older Backup and Restore (Windows 7) system image have no password or encryption setting, so the copy is only as safe as the drive it's on, and device encryption doesn't cover external drives. Encrypt the backup drive with BitLocker To Go (Windows Pro, Enterprise or Education), use an encrypted 7-Zip archive or VeraCrypt container, or encrypt the files first. Keep the password or recovery key away from the backup.

What each Windows backup does, and where it goes

  • Windows Backup (the app). Select Start, type backup and select Windows Backup. It syncs the Desktop, Documents, Pictures, Videos and Music folders you switch on to OneDrive, and stores settings, apps and "Accounts, Wi-Fi network and passwords" with your Microsoft account. It needs a personal Microsoft account; a free one includes 5 GB of OneDrive storage.
  • File History. In Control Panel, under System and Security, select Save backup copies of your files with File History. It copies your libraries to an external drive or network location and keeps earlier versions. Microsoft's steps include no password or encryption option.
  • Backup and Restore (Windows 7). The legacy Control Panel tool that saves a system image, a copy of the whole drive, to a hard disk, DVDs or a network location. Microsoft deprecated it in Windows 10 version 1709 and suggests a third-party product for full-disk backups. No password option either.

What someone with your backup can read

Encryption on your PC doesn't travel with the copy. Microsoft's BitLocker FAQ says encrypted sectors are decrypted "as they're requested from system read operations", so a backup tool reads your files in readable form and writes them out that way unless the backup drive is encrypted too. Device encryption "doesn't encrypt external/USB drives".

So treat an unencrypted backup drive like an open folder: whoever has it can open your documents and photos on another PC, including earlier versions and files you've since deleted. A system image holds the whole drive.

In OneDrive, Microsoft says each file "is encrypted at rest with a unique AES256 key" and travels over TLS. That protects it in Microsoft's data centers, not from someone who gets into your account. Microsoft's extra layer is Personal Vault, a OneDrive folder that asks for a second check, such as a fingerprint, PIN or code, and locks after 20 minutes of inactivity on the web. Without a Microsoft 365 Personal or Family subscription it holds only three files.

Three ways to make an encrypted backup

1. Encrypt the backup drive with BitLocker To Go (Pro, Enterprise, Education)

Microsoft says BitLocker "isn't available on Windows Home edition". On a Pro, Enterprise or Education PC:

  1. Sign in with an administrator account and connect the backup drive.
  2. Select Start, type BitLocker and select Manage BitLocker.
  3. Find the drive. USB sticks are under Removable data drives - BitLocker To Go; an external hard disk may be under Fixed data drives. Select Turn on BitLocker.
  4. Choose to unlock the drive with a password.
  5. Back up the recovery key to your Microsoft account, a file or a printout, never to the backup drive.
  6. Let encryption finish, then point File History (or your copy job) at the drive.

From then on, Microsoft says, blocks "are encrypted before the system writes them to the physical disk", and the drive locks when you unplug it. Microsoft's 2012 File History design post says it supports BitLocker "on both source and destination drives". The drive opens with its password on other computers, but Microsoft doesn't document unlocking it on Windows Home, so test first. File History can't save to the drive while it's locked; Microsoft's FAQ says you can turn on automatic unlocking for it in Manage BitLocker (for a fixed data drive, only if the Windows drive also uses BitLocker). More: encrypting a USB drive without BitLocker.

2. An encrypted 7-Zip archive or VeraCrypt container (any edition)

The free 7-Zip offers "strong AES-256 encryption in 7z and ZIP formats". This packs your Documents folder into one encrypted archive on the backup drive:

-p with nothing after it makes 7-Zip ask for the password, so it stays out of your command history. 7-Zip asks only once and doesn't ask you to confirm it, so the t step is your check: it asks again, and if it reports a wrong password, delete the archive and run the command again. -mhe=on encrypts the file names too. The command asks Windows where your Documents folder is: if Windows Backup is on, Documents lives inside your OneDrive folder. Each archive is a snapshot, not a running history.

VeraCrypt, free and open source, "creates a virtual encrypted disk within a file and mounts it as a real disk". Put the container on the backup drive, mount it and copy into it. Installing VeraCrypt needs administrator rights.

Keep the key away from the backup

An encrypted backup is useless without its password or recovery key. Microsoft says BitLocker "is designed to make the encrypted drive unrecoverable without the required authentication"; 7-Zip and VeraCrypt have no password reset; and if you lose both your Clavis password and recovery key, nobody can recover your files. Keep the key somewhere you control that isn't the backup drive or the PC (Microsoft warns against keeping a recovery key with the computer), then test a restore. Lost a BitLocker key? See where your BitLocker recovery key is.

What can go wrong

  • Old unencrypted backups. Backups already on other drives or DVDs stay readable. Encrypt or wipe them.
  • Decrypted working copies. File History "continuously monitors your files and folders", so a file you decrypt to edit can be backed up while it's readable, and File History keeps that version. Encrypt it again when you're done, and remove that version from the backup.
  • A lost password or key. No reset. Keep two copies of the key, in different places.
  • Windows Home. No BitLocker To Go. Use option 2 or 3.
  • Your Microsoft account. A OneDrive backup is only as safe as the account's password and sign-in checks.

Questions

Is Windows Backup encrypted?

Not with a password of your own. The Windows Backup app syncs your folders to OneDrive, where Microsoft encrypts each file at rest with its own AES256 key, but anyone who signs in to your Microsoft account can open them.

Is File History encrypted?

File History has no password or encryption setting. Its copies are encrypted only if the drive it saves to is, for example with BitLocker To Go on Windows Pro, Enterprise or Education.

Is there an encryption key for Windows Backup?

No. Windows Backup, File History and Backup and Restore (Windows 7) don't give you a key of their own. If your backup drive uses BitLocker To Go, its password and BitLocker recovery key unlock it, so save the recovery key to your Microsoft account, a file or a printout, never on the backup drive.

Does BitLocker or device encryption protect my backup drive?

Not unless the backup drive itself is encrypted. BitLocker on your PC's drive decrypts data as it's read, so backups are written in readable form, and device encryption doesn't cover external or USB drives. Turn on BitLocker To Go for the backup drive (Pro, Enterprise or Education), or use an encrypted archive or container.

Is a system image backup encrypted?

The Backup and Restore (Windows 7) tool, deprecated since Windows 10 version 1709, has no password option. Treat the image as readable by anyone with the drive unless that drive is encrypted.

How do I encrypt my backup on Windows 11 Home?

Home can't turn on BitLocker To Go. Use an encrypted 7-Zip archive, a VeraCrypt container, or encrypt the files first with a tool such as Clavis Encrypt.
