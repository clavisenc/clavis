Clavis settings explained

Open Settings from the sidebar. Changes take effect when you press Save.

Security and auto-lock

  • Session timeout — Clavis locks the vault after this many minutes without activity.
  • Argon2id — how hard Clavis makes each password guess. Tune for this PC picks the strongest setting that still unlocks quickly on your computer. It applies to files you encrypt from now on.
  • Lock on system sleep and lock on session deactivate (locking Windows or switching user) lock the vault straight away.

Unlock with Windows Hello

Tick Unlock with Windows Hello, confirm your vault password, then confirm twice with your face, fingerprint or PIN. From then on Clavis asks Windows Hello first when you unlock; cancel it to type your password instead. It's free.

  • Your password is stored sealed with a key that only Windows Hello can recreate after you verify yourself, so the file alone (copied, or read by other software) doesn't reveal it.
  • Changing your password turns it off; turn it on again afterwards. It isn't offered for a vault that uses a key file, so Windows Hello never skips your second factor.
  • Windows Hello needs a PIN, face or fingerprint set up in Windows Settings → Accounts → Sign-in options.

Updates and Explorer

Clavis checks for updates once a day (untick to turn that off) and every update is signature-checked before it's installed. The Explorer option adds or removes the right-click menu.

Performance

Compression level trades speed for smaller files. Already-compressed files like photos, videos and ZIPs barely shrink.
