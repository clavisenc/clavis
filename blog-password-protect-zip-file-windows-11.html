How to password protect a zip file in Windows 11 (and 10)

You right-click a folder, make a compressed (zipped) folder, and look for a password box. There isn't one. Here is what Windows' built-in zip can and can't do, according to Microsoft, how to make a password-protected zip or 7z with the free 7-Zip, which encryption to choose, and the one thing a zip password never hides.

Short answer: Windows 11 and 10 can't put a password on a zip file by themselves. Their compressed folders have no password option, and Microsoft says Windows 11 doesn't support encrypted archives, pointing to apps such as 7-Zip or WinRAR. With the free 7-Zip, right-click the files, choose 7-Zip → Add to archive..., type a password and set Encryption method to AES-256, or use the 7z format and tick Encrypt file names. In a .zip the file names stay visible even with a password, and the password should travel separately from the file.

What Windows can and can't do on its own

  • Compressed (zipped) folder. Microsoft's steps: right-click the file or folder, select Show more options → Send to → Compressed (zipped) folder. There's no password step, on Windows 11 or 10.
  • Other formats, same answer. Microsoft says Windows 11 version 24H2 supports ZIP, RAR, 7z and TAR, "However, it does not support operations on encrypted archive files", and suggests non-Microsoft apps such as 7-Zip or WinRAR.
  • PowerShell's Compress-Archive has no password parameter either. See encrypting a file with PowerShell for what PowerShell can do.
  • "Encrypt contents to secure data" (EFS) isn't a password and isn't in Home editions. Microsoft warns that encrypted files added to a zipped folder are unencrypted when they're unzipped.

So "without software" has no built-in answer. Two ways that add nothing new to your PC: if you have Microsoft Office, Word and Excel files can carry their own password (see password-protecting Word and Excel files), or zip the folder with Windows and encrypt the zip on our browser page, where the file and password never leave your device (up to 2 GB at a time on a computer, 1 GB on a phone). That gives an .enc file, not a password-protected zip, and the other person opens it at clavisenc.com/open.html.

Step by step: a password-protected zip with 7-Zip

This works on any edition of Windows 11 and 10, Home included.

  1. Download 7-Zip from 7-zip.org (pick the installer that matches your Windows: 64-bit x64, ARM64 or 32-bit x86) and install it.
  2. In File Explorer, select the files or folder and right-click. On Windows 11, select Show more options if 7-Zip isn't in the menu. Point to 7-Zip and select Add to archive....
  3. Set Archive format: zip if the other person expects a zip, 7z if they can use 7-Zip (it can hide file names).
  4. Under Encryption, type the password in Enter password and again in Reenter password.
  5. For zip, set Encryption method to AES-256. For 7z, the method is always AES-256: tick Encrypt file names.
  6. Select OK. Your originals stay where they were unless you ticked Delete files after compression.
  7. Check it: right-click the new archive, point to 7-Zip and select Test archive, and enter the password when asked.

To open it, right-click, point to 7-Zip, select Extract files... and type the password in the Password box. From the command line, see the 7-Zip command line guide.

ZipCrypto or AES-256?

For zip, 7-Zip offers both, and its command-line default is ZipCrypto. 7-Zip's help puts the trade-off plainly: ZipCrypto is compatible "with most of the ZIP archivers"; AES-256 "provides stronger encryption", but is supported "only by 7-Zip, WinZip and some other ZIP archivers". PKWARE, which publishes the ZIP specification, calls the traditional ZIP encryption (ZipCrypto) "weak by today's standards" and recommends it only for low security needs or compatibility with older programs; a known-plaintext attack on it was presented in 1994. Choose AES-256. If the other person truly can't open that, don't rely on ZipCrypto for anything sensitive.

The file names stay visible in a zip

A password on a .zip protects what's inside the files, not the list of files. 7-Zip's manual says it doesn't encrypt file names in zip archives, so anyone with the zip can see names such as Passport scan.pdf or Salary 2026.xlsx, with their sizes and dates, without the password. Use the 7z format with Encrypt file names, or give the files neutral names before zipping.

Send the password separately

Anyone who has both the file and the password can open it. Send the file one way (email, a cloud link, a USB stick) and the password another (a phone call, a text message, a different chat app). Don't put it in the same email, in the subject line or in the file name. More options: encrypting files before emailing them.

What can go wrong

  • A forgotten password means lost files. 7-Zip can't recover it, so store it in a password manager.
  • ZipCrypto by accident. Check the Encryption method box says AES-256 before you select OK.
  • Revealing file names. A zip shows them to anyone. Use 7z with Encrypt file names.
  • The other person can't open it. Microsoft says Windows 11 doesn't support encrypted archives, so tell them to install 7-Zip or a similar tool.
  • The originals are still on your PC, unencrypted. The archive is a copy. For files you keep, encrypt the files themselves, and use BitLocker or device encryption for the drive as a separate layer.

Questions

Can you password protect a zip file in Windows 11 without software?

No. Windows can make a compressed (zipped) folder but has no password option, and Microsoft says Windows 11 doesn't support encrypted archives. Without installing anything new, you can add a password inside Word and Excel files if you have Microsoft Office, or zip the folder and encrypt the zip on a browser page such as clavisenc.com/encrypt.html, which gives an .enc file instead of a zip.

How do I password protect a zip file in Windows 10?

The same way as on Windows 11: install the free 7-Zip, right-click the files, choose 7-Zip, then Add to archive..., pick zip, type the password twice and set Encryption method to AES-256. Windows 10's own compressed folders have no password option.

Why is there no password option when I compress a folder in Windows?

Windows' built-in compression doesn't do encryption. Microsoft says Windows 11 version 24H2 supports ZIP, RAR, 7z and TAR but not operations on encrypted archive files, and suggests apps such as 7-Zip or WinRAR.

Should I use ZipCrypto or AES-256?

AES-256. PKWARE, which publishes the ZIP specification, calls ZipCrypto weak by today's standards. 7-Zip notes that AES-256 zips need 7-Zip, WinZip or some other zip programs to open, while ZipCrypto works with most.

Can someone see what's in a password-protected zip?

They can't read the files' contents without the password, but they can see the file names, sizes and dates. 7-Zip can't encrypt file names in a zip. Use the 7z format with Encrypt file names to hide them.

Can Windows open a password-protected zip?

Don't count on it. Microsoft says Windows 11 doesn't support operations on encrypted archive files and recommends 7-Zip or WinRAR. Tell the other person to install one of them, or 7-Zip in particular for AES-256 zips and 7z files.

What if I forget the password to my zip file?

There is no reset. The archive can't be opened without the password, so keep it in a password manager and keep your originals until the other person has opened their copy.
