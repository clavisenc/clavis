    What is a .enc file?

    .enc is short for "encrypted". A file with that ending is locked: its content can't be read without the right password or key. The ending doesn't belong to any one program, so different programs write different kinds of .enc file.

    A Clavis .enc file holds one encrypted file, protected with AES-256-GCM, with its original name stored inside. If someone sent it to you, it was probably made with Encrypt online or Send with a password in the app, and it has a name like report.pdf.enc. Files you encrypted in the Clavis Encrypt app have random names, and the real name comes back when you open them.

    How to open a .enc file online

    1. If the file came by email, a chat app or a link, save it to your phone or computer first.
    2. Press Choose or drop .enc files at the top of this page and pick the file. You can pick several, if they share one password.
    3. Type the Password. If someone sent you the file, ask them for it. For your own files, it's the vault password you used when you encrypted them.
    4. If your vault uses a key file, open My vault uses a key file and choose it.
    5. Press Open and wait a few seconds.
    6. Press Save name to keep the file. For PDFs, images and text files, View shows it first.

    What this page can't open

    • .enc files from other programs. The page says "This isn't a Clavis Encrypt file." Open those with the program that made them; ask the sender if you're not sure which one it was.
    • Files made with Encrypt for someone. They open only in Clavis Encrypt, with the recipient's Clavis ID.
    • Team folder files. They open only in Clavis Encrypt, for members of the team folder. This page shows "Wrong password or key file" for them.
    • Any file without its password. Neither this page nor we can get a lost password back for you.

    Good to know

    • Opening takes a few seconds: the same deliberate slowness that protects your password from guessing.
    • Very large files (over about 1 GB) may not fit in a phone's memory; open those on a computer.
    • The copy you save is an ordinary, unlocked file. On a shared or borrowed device, delete it when you've finished. Your .enc file isn't changed.
    • This page works the same way as the free open-source decryptor; the file format is public. This page's code hasn't been independently audited (see Security).
    • To send a file back locked with a password, encrypt a file in your browser, on this phone or computer.
    • For files you keep, whole folders, watch folders and more, get Clavis Encrypt.

    Questions

    How do I open a .enc file?

    If Clavis Encrypt made it, choose the file on this page, type its password and press Open. That works on any phone or computer with a current browser, and you don't need to install anything. If another program made it, you need that program.

    Can I decrypt a file online without uploading it?

    Yes, on this page. Its code runs in your browser, and the page's security policy stops that code from connecting anywhere, so the file and the password are never uploaded. The only thing the page sends is a cookieless count (a visit, and "a file was opened") to the site's analytics, with no file name, size, content or password. As with any web page, you're trusting the code the site sends you. The file format is public, so you can check a file with the open-source decryptor. The code hasn't been independently audited.

    Can this page open any .enc file?

    No. It opens files made with Clavis Encrypt or with this site's Encrypt online page. Other programs use the .enc ending for their own formats, and the page will say "This isn't a Clavis Encrypt file." It also can't open files made with Encrypt for someone or files from a team folder: those open only in Clavis Encrypt.

    Can I open a .enc file without the password?

    No. Without the password the file can't be decrypted, and neither this page nor we can get a lost password back for you. If someone sent you the file, ask them for the password. If it's your own file and you forgot your vault password, use your recovery key in the Clavis Encrypt app; this page can't use one.

    Why does it say "Wrong password or key file"?

    The file wouldn't open with what you entered. Check the capital letters and spaces, and if your vault uses a key file, choose it under My vault uses a key file. Team folder files show this message too, because they open only in Clavis Encrypt.

    Why does it say the file was damaged or altered?

    Part of the file has changed since it was encrypted, or it didn't finish downloading. Clavis checks this every time and won't give you a changed file. Download it again or ask the sender for a new copy.

    Does it work on iPhone and Android?

    Yes, in a current Safari, Chrome, Edge or Firefox. Very large files (over about 1 GB) may not fit in a phone's memory, so open those on a computer.

    Is it free?

    Yes. There's no account, no sign-up and no limit on how often you use it.
