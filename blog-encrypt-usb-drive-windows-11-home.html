How to password-protect or encrypt a USB drive without BitLocker (Windows 11 and 10 Home)

A USB flash drive is easy to lose. It falls out of a bag, stays in a print shop's computer, or gets borrowed and never comes back. Whatever is on it goes with it: ID scans, tax papers, a photo backup. On Windows Pro you'd lock the stick with BitLocker To Go. On Windows 11 Home and Windows 10 Home there's no password option for a USB stick, thumb drive, pen drive or external hard drive. Here are the ways that do work, which one fits your situation, and what happens if you forget the password.

Short answer: Windows 11 and 10 Home can't password-protect a USB drive by themselves. Microsoft says BitLocker “isn't available on Windows Home edition”, and device encryption “doesn't encrypt external/USB drives”. Instead, use a 7-Zip 7z archive (AES-256, tick Encrypt file names), VeraCrypt (needs admin rights), Clavis Encrypt (free, no admin rights), or BitLocker To Go set up on a Pro PC. Keep a second copy.

Why Windows Home has no password option for USB drives

Two Microsoft facts explain it, and both apply to Windows 11 and Windows 10:

  • No BitLocker on Home. BitLocker, which includes BitLocker To Go for removable drives, “is only available on devices running Windows Pro, Enterprise, or Education editions. It isn't available on Windows Home edition.”
  • Device encryption stops at the PC. Many Home PCs have device encryption (it depends on the hardware), but it “encrypts only the OS drive and fixed drives, it doesn't encrypt external/USB drives.” A file you copy from an encrypted Home PC lands on the stick unencrypted.

To check which edition you have, on Windows 11 or Windows 10:

  1. Right-click Start and choose Settings.
  2. Select System, then About.
  3. Under Windows specifications, check the edition.

If it says Home, read on. If it says Pro, Enterprise or Education, skip to BitLocker To Go. For what device encryption does and doesn't cover on your PC, see device encryption vs BitLocker on Windows 11 Home.

Option 1: a password-protected 7-Zip archive

The free 7-Zip offers “strong AES-256 encryption in 7z and ZIP formats”. It works on every edition of Windows.

  1. Install 7-Zip from 7-zip.org.
  2. Select your files in File Explorer and right-click → 7-Zip → Add to archive… (on Windows 11 you may need Show more options first).
  3. Set Archive format to 7z.
  4. Under Encryption, type the password twice, keep AES-256, and tick Encrypt file names, so even the file names stay hidden without the password.
  5. Save the archive to the USB drive and press OK. On a FAT32 stick, keep each archive under 4 GB.
  6. Open the archive once to check the password works.

Build the archive from copies on your PC and save it to the stick. If the originals were already on the stick, deleting them is best effort on flash (what deleting from a USB stick really does).

  • Catch: copies left behind. To edit a file you extract it, change it and pack it again. The extracted copies stay wherever you put them, often on someone else's PC.
  • Catch: no reset. A lost password can't be recovered.

Option 2: VeraCrypt

VeraCrypt is free and open source. It can keep an encrypted container file on the stick, which you mount as a drive letter, or encrypt the whole USB drive.

  1. Install VeraCrypt on your PC. This needs administrator rights.
  2. Press Create Volume, choose Create an encrypted file container, and save the container file on the USB drive. Pick a size (under 4 GB on a FAT32 stick) and a password. (To encrypt the whole drive instead, choose Encrypt a non-system partition/drive, but read the whole-drive catch below first: on many sticks it erases everything.)
  3. In VeraCrypt, pick a free drive letter in the list, press Select File and choose the container, then press Mount and enter the password. The container appears as that drive letter.
  4. Unmount it in VeraCrypt before you unplug the stick. VeraCrypt's FAQ warns that unplugging first can lose data.
  • Good: strong, free, and VeraCrypt volumes are “fully cross-platform” (Windows, macOS, Linux).
  • Catch: admin rights everywhere. Standard users can only use VeraCrypt “after a system administrator installs VeraCrypt”. Its documentation also says “you need administrator privileges in order to be able to run VeraCrypt in portable mode”. Office, school and library PCs are usually out.
  • Catch: whole-drive mode can erase the stick. VeraCrypt can encrypt in place only a partition, and “only partitions that contain an NTFS filesystem can be encrypted in place.” Many sticks are formatted FAT32 or exFAT, and on those the whole-drive choice left is Create encrypted volume and format it, which erases everything on the stick. On an NTFS stick, select the partition, not the whole disk, and choose Encrypt partition in place. Never choose Create encrypted volume and format it on a drive with files you need. VeraCrypt also warns that if the power is cut or the PC crashes during in-place encryption, “portions of the data will be corrupted or lost”, so back up first.
  • Catch: after whole-drive mode. You can't run VeraCrypt from the stick, and Windows may offer to format it when you plug it in. Don't accept; mount it in VeraCrypt.
  • Catch: no reset. “VeraCrypt does not allow decryption of data without knowing the correct password or key.”

Option 3: encrypt the files on the stick with Clavis (Free)

Clavis Encrypt encrypts files, one or several at a time, so you can lock what's on a USB stick or external drive without a container, an archive or a Pro edition of Windows. Clavis Free covers this. To be clear: Clavis encrypts files, not the drive. Files you add to the stick later stay unencrypted until you encrypt them, and Clavis doesn't replace BitLocker To Go or a drive's own hardware encryption.

  1. Download Clavis and install it. The installer installs just for you, so Windows doesn't ask for administrator rights.
  2. Create your vault. Write down or print the recovery key it shows you, and keep it somewhere other than the stick.
  3. Plug in the stick and open it in File Explorer.
  4. Select one file or several and right-click → Show more options → Clavis → Encrypt (on Windows 10, Clavis is right in the menu). The right-click menu exists only in the direct-download installer. In the Microsoft Store version, drag the files onto the Clavis window instead, choose Encrypt and press Encrypt now.
  5. Clavis lists what it's about to encrypt. Check the list and confirm.

Each file becomes a .enc file with a random name; the real name is stored inside, encrypted. Clavis Free encrypts one file or several at once; Clavis Pro ($19 once) also encrypts a whole folder in one go.

  • FAT32 sticks. Many sticks use FAT32, which can't hold a file of 4 GB or more (Microsoft lists its maximum file size as 4 GiB). Clavis tells you before it writes anything.
  • Encrypt on the PC first. Clavis overwrites and deletes the original after encrypting it, but on flash that's best effort: the stick can keep old copies where no app can reach (what deleting from a USB stick really does). The safest habit is to encrypt files on your PC, then copy the .enc files to the stick.
  • Opening them elsewhere. Use Clavis with your vault (Windows 10 and 11, or Linux), or open them at clavisenc.com/open.html in any browser, on a phone or Mac too. Nothing is uploaded.
  • What you're trusting. Clavis is closed source and hasn't been independently audited. The .enc format is public, and a free open-source decryptor opens any file with your password.

Open the stick on PCs where you can't install anything

On office, school or library PCs, tools you'd have to install are usually out. With Clavis Pro, USB Stick → Set up stick copies Clavis, your vault and a page called Open my files.html to the stick, so you run Clavis from the stick, or open the page where the PC blocks programs on USB sticks. On Clavis Free and the Microsoft Store version, Add the page only puts just the page on the stick, or you can open each file at clavisenc.com/open.html. Your key file, Windows Hello and recovery key are not copied to the stick. Whichever tool you use, malware on someone else's PC can record your password as you type it, so only unlock the stick on PCs you trust. Option 4: BitLocker To Go, set up on a Pro PC

If you can use a PC running Windows 11 or 10 Pro, Enterprise or Education, BitLocker To Go there encrypts the whole drive. Microsoft says it covers “USB flash drives”, “SD cards”, “external hard disk drives” and other drives formatted with NTFS, FAT16, FAT32 or exFAT. Microsoft's BitLocker FAQ says “standard users can turn on, turn off, or change configurations of BitLocker on removable data drives”, though Microsoft's own consumer steps start with signing in with an administrator account, and on a work PC a policy can stop users using BitLocker on removable drives at all.

  1. Plug the drive into the Pro PC. Select Start, type BitLocker and select Manage BitLocker.
  2. Find the drive under Removable data drives - BitLocker To Go and select Turn on BitLocker.
  3. Choose to unlock the drive with a password, and type it.
  4. Back up the recovery key. Microsoft offers your Microsoft account, a file, or a printout. On a borrowed or work PC, print it, or save the file and then move it somewhere you control (not the stick), so it isn't left on that PC. Choose the Microsoft account only if you're signed in with your own. On a PC managed by a work or school, Microsoft says this option may read “Save to your Azure AD account” instead: that's the organization's account, not your personal one. By default Windows won't save a removable drive's recovery key to a removable drive, and it should never be on the stick itself.
  5. Choose how much of the drive to encrypt. Used Disk Space Only “can reduce encryption time by more than 99 percent, depending on how much data that needs to be encrypted”, but Microsoft calls it “not the most secure way to encrypt a drive”. On a stick that has held private files before, encrypt the whole drive: Microsoft's planning guide warns that with used-space encryption, “sectors where previously unencrypted data are stored can be recovered through disk-recovery tools until they're overwritten”.
  6. Follow any remaining screens in the wizard and start encrypting. Wait for it to finish before you remove the drive.

From then on, anything saved to the drive is encrypted as it's written, and “a removable data drive will also be locked automatically when the drive is removed from the computer.” Microsoft says a BitLocker To Go drive “can be opened by using a password or smart card on another computer”, but it doesn't document unlocking one on Windows Home. Test the drive on your Home PC before you put anything important on it. Microsoft doesn't document Mac or Linux either.

Password-protect an external hard drive or portable SSD

Everything above works on external hard drives and portable SSDs too. Three things are different.

1. Check whether the drive already has hardware encryption. Some drives encrypt inside the drive, and you only need to set a password:

  • WD My Passport: WD's manual says WD Security “implements password protection and the 256-bit hardware data encryption” of supported drives. On a PC without WD's software, the drive shows a WD Drive Unlock utility for typing the password. But WD also says “not all of Western Digital's products contain active data encryption”, that in some markets encryption is disabled, and that “drives with hardware encryption may not work in other enclosures or be readable by other systems.” If you forget the password, “you will have to erase the drive before you can use it again.”
  • Samsung T7 portable SSD: Samsung lists “AES 256-bit hardware encryption” and optional password protection with Samsung Portable SSD Software.

With hardware encryption you need the maker's software (or its unlock utility) on each PC, and you're trusting the maker's firmware. A lost password usually means lost data.

2. Know which methods keep the files already on the drive. Back up the drive first whichever you pick.

  • VeraCrypt, encrypt in place: keeps your files, but only on an NTFS partition. VeraCrypt's FAQ says a non-system partition can be encrypted without losing data if it “contains an NTFS filesystem”. Select the partition, not the whole disk (see the whole-drive catch above).
  • VeraCrypt, new volume on the drive (Create encrypted volume and format it): erases it, and on a FAT32 or exFAT drive it's the only whole-drive choice. VeraCrypt itself notes that creating an empty encrypted volume on a partition or device is a way to securely erase it. A container file, by contrast, sits beside your other files.
  • BitLocker To Go: encrypts the drive with your files on it.
  • 7-Zip and Clavis: work on files and leave the drive as it is.

3. Big drives take time. Microsoft says encryption time depends on the drive's size and speed, and suggests encrypting large drives when they aren't in use. Keep the password and recovery key off the drive. Clavis Pro's USB stick mode also works with portable USB SSDs and hard disks.

Other routes you'll come across

  • Paid “BitLocker for Home” tools. Hasleo BitLocker Anywhere says it “can be run not only on Windows Home editions” and encrypts the Windows drive and data partitions with BitLocker, listing USB drives and SD cards among supported devices. It's paid, with a free trial. These are the vendor's claims; we haven't tested it.
  • Hardware-encrypted USB sticks. Some sticks encrypt inside the stick and are unlocked with a password or a keypad on the stick. Kanguru, for example, sells a “Defender” line. When people search for “Defender encrypted USB”, they usually mean a stick like this: a product you buy, not a Windows feature. Check the maker's own documentation for what it protects.

Does Microsoft Defender encrypt USB drives?

No. Microsoft describes Microsoft Defender Antivirus as “built-in anti-malware and antivirus protection”. Encrypting drives is BitLocker's job, which Microsoft describes as a Windows feature that “provides encryption for entire volumes”.

Microsoft Defender for Endpoint is a business product run by IT teams. Its device control can “allow users to install and use only BitLocker-encrypted devices”. Separately, BitLocker policy on a company PC can “mount any data drives that aren't protected by BitLocker as read-only”, and Windows can also “deny write to all removable media”. So if your work PC opens your USB stick but won't save to it, that's often company policy, such as these BitLocker or device-control rules. Ask your IT team; it's their rule to change, not yours.

Can you password-protect a USB drive without encryption or software?

Not on an ordinary stick. Windows Home has no built-in password option for USB drives, and tools that only show a password prompt or only hide files, without encrypting them, leave the files readable to anyone who reads the flash directly. The one no-software route is a drive that encrypts itself, such as a keypad stick (see Other routes).

If you forget the password

  • 7-Zip: no way back.
  • VeraCrypt: no way back.
  • Clavis: the one-time recovery key you saved when you created the vault.
  • BitLocker To Go: the recovery key, if you saved it somewhere other than the drive.
  • Hardware-encrypted drives: per the maker; usually the data is lost. WD says you must erase the drive.

Keep a second copy

Encryption stops people reading your files. It doesn't stop a stick from failing, breaking or getting lost. Keep the originals, or an encrypted backup, somewhere other than the stick, and keep your password and recovery key somewhere other than the stick too.

Questions

How do I put a password on a USB flash drive without BitLocker in Windows 11?

Use a password-protected 7-Zip archive (7z format, AES-256, Encrypt file names ticked), a VeraCrypt container or encrypted drive (needs administrator rights), or a file-encryption app such as Clavis Encrypt, which encrypts the files on the stick for free without administrator rights. All of these work on Windows 11 Home, where BitLocker isn't available.

How do I password-protect a USB drive in Windows 10 without BitLocker?

The same way as on Windows 11: a 7-Zip archive, VeraCrypt or Clavis Encrypt. Windows 10 Home has no BitLocker either, and its device encryption doesn't cover USB drives. On Windows 10 the 7-Zip and Clavis items are directly in the right-click menu, without Show more options. (Clavis's right-click menu comes with the direct-download installer only; in the Microsoft Store version, drag the files onto the Clavis window.)

Can Windows 11 Home use BitLocker To Go?

Not to set it up. Microsoft says BitLocker isn't available on Windows Home edition. A drive encrypted with BitLocker To Go on a Pro PC can be opened with its password on another computer, Microsoft says, but it doesn't document unlocking on Home, so test the drive on your Home PC before you rely on it.

Does device encryption protect my USB stick or external drive?

No. Microsoft says device encryption encrypts only the OS drive and fixed drives, and doesn't encrypt external or USB drives. Files you copy to a stick or external drive are not encrypted unless you encrypt them yourself.

How do I password-protect a USB stick for free?

Put the files in a password-protected 7-Zip archive, create a VeraCrypt container on the stick, or encrypt the files with Clavis Free. All three are free. If you can use a Windows Pro PC, BitLocker To Go is built in there.

Can I encrypt a USB stick without admin rights?

Yes, with Clavis Encrypt, which installs just for your account without administrator rights and encrypts the files on the stick. VeraCrypt needs administrator rights to install and to run in portable mode. On a Pro PC, Microsoft's BitLocker FAQ says standard users can turn on BitLocker To Go for removable drives, though a work PC's policy can block it.

How do I password-protect an external hard drive on Windows 11 Home?

First check whether the drive has its own hardware encryption, such as WD Security on a WD My Passport or password protection on a Samsung T7. If not, use VeraCrypt (encrypt in place keeps your files, on an NTFS partition only), BitLocker To Go set up on a Pro PC, or encrypt the files with 7-Zip or Clavis. Back up the drive first.

Can I encrypt an external drive without formatting it?

Yes. BitLocker To Go encrypts the drive with your files on it, and VeraCrypt can encrypt a partition in place without losing data if it's formatted NTFS. On a FAT32 or exFAT drive, VeraCrypt's only whole-drive choice is a new volume (Create encrypted volume and format it), which erases the drive; a VeraCrypt container file doesn't. 7-Zip and Clavis work on files and don't touch the drive's format. Back up first either way.

Does Microsoft Defender encrypt USB drives?

No. Microsoft Defender Antivirus scans for malware. Microsoft Defender for Endpoint, a business product, can make company PCs accept only BitLocker-encrypted USB drives, but BitLocker does the encrypting. “Defender encrypted USB” usually means a hardware-encrypted stick you buy, such as Kanguru's Defender line.

Will it open on another PC or a Mac?

Only with the right tool and the password. VeraCrypt volumes open on Windows, macOS and Linux with VeraCrypt installed. Clavis .enc files open in Clavis on Windows or Linux, or in any browser at clavisenc.com/open.html, Mac included. A 7z archive needs an app that opens encrypted 7z files on that device. Microsoft doesn't document BitLocker To Go on Home, Mac or Linux, so test first.

Is it safe to keep my only copy on an encrypted stick?

No. Encryption protects against people reading the files, not against the stick breaking or getting lost. Always keep a second copy somewhere else, and keep the password and recovery key off the stick.
