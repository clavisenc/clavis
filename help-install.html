Install Clavis on Windows or Linux

Clavis runs on Windows 10 and 11 (64-bit) and on 64-bit Linux with a .deb package (Ubuntu, Debian and their derivatives). There's no account to create and nothing to sign in to: everything happens on your computer.

Windows

  1. Go to the download page and get Clavis-Setup.exe.
  2. Double-click it. If Windows SmartScreen says "Windows protected your PC", choose More info → Run anyway. That message appears for new apps that haven't built up a download history yet.
  3. The setup wizard walks you through it: Next, accept the terms, keep the suggested folder (or choose another), choose whether you want desktop and Start menu shortcuts, then Install. Clavis Encrypt installs just for you, so Windows doesn't ask for administrator rights.
  4. Leave Launch Clavis Encrypt ticked and click Finish. The first thing you'll see is Create your vault. Later, start it from the Start menu or the desktop shortcut.

Prefer not to install? The portable ZIP on the same page runs anywhere: unzip it and start Clavis.exe.

Check your download. The download page lists a SHA-256 checksum for every file. In PowerShell, Get-FileHash .\Clavis-Setup.exe should print the same value.

Linux

  1. Download Clavis-linux.deb from the download page.
  2. Install it from a terminal in the download folder: sudo apt install ./Clavis-linux.deb
  3. Start Clavis from your applications menu. The command line is at /opt/clavis/bin/clavis-cli.

Updating

On Windows, Clavis checks for updates once a day and offers new versions; press Settings → Updates → Check now to check straight away. An update installs when Clavis restarts, and Clavis refuses any update whose signature doesn't match. On Linux, install the newer .deb the same way. Your vaults and settings are kept either way.

Uninstalling

Windows: Settings → Apps → Installed apps → Clavis → Uninstall. Linux: sudo apt remove clavis. Decrypt anything you still need first — encrypted files can only be opened with Clavis and your vault.
