How to hide a folder in Windows 11 (and really lock it)

You want a folder out of sight: tax papers, private photos, a gift list. Windows 11 can hide it in a few clicks, and one Command Prompt line hides it a little more. Here are both, what hiding can't do, how to keep files from other people on the same PC, and what to use when you want a password.

Short answer: Right-click the folder, select Properties, tick Hidden and select OK. It disappears from File Explorer until someone selects View → Show → Hidden items. In Command Prompt, attrib +h +s followed by the folder's path also marks it as a system item, so it stays out of sight even then, until someone unticks Hide protected operating system files. Neither is protection: anyone using your account can reveal it, dir /a lists it, and administrators can open every unencrypted file. Windows has no folder password; to keep a folder private, encrypt its files.

Hide a folder with Properties (every edition)

It works on Windows 11 and 10, every edition, and for single files too.

  1. In File Explorer, right-click the folder and select Properties.
  2. On the General tab, next to Attributes, tick Hidden.
  3. Select OK. In Confirm Attribute Changes, choose Apply changes to this folder only or Apply changes to this folder, subfolders and files, then select OK. The second hides every item inside as well.
  4. If the folder is still visible, File Explorer is set to show hidden items. Select View → Show and clear Hidden items.

To unhide it, turn Hidden items back on, open the folder's Properties and clear Hidden. If you hid its contents too, choose Apply changes to this folder, subfolders and files again. On Windows 10, the switch is under View → Options → Change folder and search options, on the View tab: Show hidden files, folders, and drives.

Hide it more completely with attrib +h +s

  1. Open Command Prompt: select Start, type cmd and select Command Prompt.
  2. Type the command with your folder's full path in quotes, then press Enter:
    attrib +h +s "C:\Users\YourName\Documents\Private"
  3. Check it: attrib "C:\Users\YourName\Documents\Private" shows S and H before the path.

What the system attribute adds. File Explorer treats an item that is both hidden and system as a protected operating system file, so turning on Hidden items doesn't show it. It appears only when someone unticks Hide protected operating system files (Recommended) in Folder Options: in File Explorer on Windows 11, select See more (…) → Options, then the View tab.

To undo it, clear both at once: attrib -h -s "C:\Users\YourName\Documents\Private". In our test, attrib -s on its own answered "Not resetting hidden file". Use attrib only on your own folders, never on Windows folders or the top of a drive.

Why hiding isn't protection

  • Two clicks reveal it. Anyone using your account can turn on Hidden items, and the protected-files box is one more tick.
  • Command Prompt lists it. Microsoft's dir reference says that with /a, dir "displays the names of all files, including hidden and system files". In our test on Windows 11 Home, dir /s /a found a file inside a folder hidden with +h +s.
  • The files open normally. Hiding locks and encrypts nothing; in the same test, a file inside opened without any prompt.
  • Administrators can open everything. Microsoft: administrators "have complete control over the system" and can "access all files".
  • Recent lists show it. Files you open from it can appear under Recent in File Explorer and in apps. Microsoft warns of this even for its own OneDrive Personal Vault.
  • Unless device encryption or BitLocker is on, the drive can be read in another PC. Microsoft's BitLocker overview notes that data on a lost or stolen device can be reached "by transferring the device's hard drive to a different device".

Hide files from other users on the same PC

If other people use the PC, separate Windows accounts do more than any hidden folder.

  1. Give each person their own account: Settings → Accounts → Other users, then Add account. Microsoft describes separate accounts as "keeping family members' data private and secure from each other".
  2. Make the other accounts standard users, and keep administrators few, as Microsoft advises.
  3. Keep private files in your own user folder (C:\Users\YourName, with your Desktop, Documents and Pictures). On our Windows 11 Home PC, its permissions list only that user, SYSTEM and the Administrators group, so other standard accounts can't open it.

For a folder elsewhere, such as on a second drive, the Security tab in its Properties sets who can open it. That works on NTFS drives only: FAT32 and exFAT, common on USB sticks, have no permissions. What permissions can't stop:

  • An administrator. By default, administrators have the right to take ownership of files, and an owner can always change permissions, even when denied access. The takeown command does exactly this.
  • Anyone signed in as you. Your account opens your files for whoever is using it.
  • Someone with the drive. Microsoft's archived EFS overview: "Permissions on files and folders does not protect against unauthorized physical attacks."

How to hide a folder with a password

No edition of Windows puts a password on a folder. Encrypt the files instead, and hide the folder too if you like:

  • EFS (Pro, Enterprise, Education): Properties → Advanced... → Encrypt contents to secure data. It never asks for a password; it unlocks with your Windows sign-in. Microsoft: "File encryption is not available in the Home edition of Windows" (why it's greyed out).
  • A 7-Zip archive: the free, open-source 7-Zip packs the folder into a 7z archive with a password and AES-256, and Encrypt file names hides the names. You extract it to use the files. It's a copy: once the archive opens with your password, delete the original folder (deleting is best effort: see what deleting really does on Windows 11). Steps: password-protecting a zip or 7z.
  • A file-encryption app such as Clavis Encrypt (below), which encrypts each file where it is.

Also turn on Settings → Privacy & security → Device encryption if your PC offers it; unlike BitLocker, it's available on Windows Home. It protects the drive, not one folder. Make sure you know where its recovery key is (with a Microsoft account, it's saved to that account): see how to find your recovery key.

What can go wrong

  • You can't find the folder again. Turn on Hidden items; for +h +s, run attrib -h -s with the path.
  • Hidden is taken for protected. Anyone who looks can find and open it.
  • A forgotten password means lost files. Nobody can open a 7-Zip archive without its password. Clavis Encrypt gives you a recovery key; keep it off the PC.
  • The unencrypted folder stays behind. 7-Zip encrypts a copy; delete the original once the archive opens.
  • Copies stay readable. Backups and cloud copies aren't hidden or encrypted just because the original is. See whether Windows backups are encrypted.

Questions

How do I hide a folder in Windows 11?

Right-click the folder, select Properties, tick Hidden and select OK. If it's still visible, clear View, Show, Hidden items in File Explorer.

How do I hide a folder in Windows 11 with a password?

Windows can't put a password on a folder. Encrypt the files instead, with a 7-Zip 7z archive (tick Encrypt file names) or an app such as Clavis Encrypt, then hide the folder too if you like. On Pro, EFS encrypts a folder but unlocks with your Windows sign-in, not a password.

How do I completely hide a folder in Windows 11?

In Command Prompt, run attrib +h +s with the folder's path in quotes. It then stays hidden even with Hidden items on, until someone unticks Hide protected operating system files. dir /a still lists it, so nothing is completely hidden. Encrypt anything private.

How do I hide files from other users on Windows 11?

Give each person their own Windows account as a standard user, and keep your files in your own user folder, which other standard accounts can't open. Administrators still can, so encrypt what really matters.

How do I make a file private in Windows 11?

Keep it in your own user folder under your own account. To keep it from administrators, anyone using your account or anyone who gets the drive, encrypt it with a password. The Hidden box works on files too, but only hides them.

Can an administrator see my hidden files?

Yes. Administrators can show hidden items, open other users' files and take ownership of files that deny them access. Files encrypted with your password they can see and delete, but not read, as long as they never get your password. An administrator can install software on the PC, so don't rely on that if the person you're hiding files from is its administrator.

How do I unhide a folder in Windows 11?

In File Explorer, select View, Show, Hidden items, then open the folder's Properties and clear Hidden. If you hid its contents too, choose Apply changes to this folder, subfolders and files again. If you used attrib +h +s, run attrib -h -s with the folder's path in Command Prompt.
