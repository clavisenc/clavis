How to encrypt a file on your phone (Android or iPhone) and send it safely

A passport scan for a landlord, a contract for a lawyer, a payslip for a bank, medical results for a family member: more and more of these leave from a phone. Phones are good at sending files and bad at locking them. iPhone and Android can hide files on the phone itself, but neither comes with a simple way to put a password on any file before you send it, and chat apps and email protect the file only part of the way. Here's how to lock any file with a password on your phone, free and without uploading it, how the other person opens it, and how this compares with what your phone already has.

Short answer: to encrypt a file on an iPhone or Android phone, open clavisenc.com/encrypt.html in Safari, Chrome, Edge or Firefox, tap Choose or drop files, enter a password of at least 10 characters (or tap Suggest a password), type it again, tap Encrypt and then Save to keep the locked .enc copy. The file is encrypted on your phone with AES-256-GCM and Argon2id, and neither the file nor the password is uploaded. Send the .enc file by email, chat or a cloud link, and send the password separately, by a call or a different app. The recipient opens it at clavisenc.com/open.html on any phone or computer, or in the free Clavis Encrypt app. It's free, with no account. If the password is lost, nobody can open the file.

What you need

  • A current browser on your phone: Safari, Chrome, Edge or Firefox. The page uses browser features that arrived in Safari 16.4, Chrome and Edge 80 and Firefox 113, so an iPhone needs iOS 16.4 or later. On an older browser the page says so instead of encrypting.
  • The file on your phone: in Files, Photos, Downloads or saved from a chat or email.
  • A way to reach the other person twice: one channel for the file (email, a chat app, a cloud link) and a different one for the password (a call, a text, another chat app).

Encrypt the file (sender)

  1. Open clavisenc.com/encrypt.html in your phone's browser.
  2. Tap Choose or drop files and pick one or more files. On iPhone you can choose from Photos or Files; on Android, from your file picker. Up to 1 GB at a time on a phone.
  3. Under Password, type a password of at least 10 characters, or tap Suggest a password for a strong one. Write it down or copy it now: nobody can recover it later. Passwords that are too easy to guess are refused.
  4. Type it again in Type it again and tap Encrypt. Each file takes a few seconds: the deliberate slowness that protects the password from guessing.
  5. Tap Save name.enc next to each file. Your browser saves it like any download (on an iPhone, usually in Files → Downloads; on Android, in Downloads). Your original file isn't changed.
  6. Send the .enc file any way you like: attach it to an email, share it in WhatsApp, Signal or Telegram, or upload it to a cloud folder and share the link. The page also writes a short Message to send with the file (with Copy message) that tells the recipient where to open it.
  7. Send the password a different way: a phone call, a text, or a different chat app. Copy password copies the one you used. Never put it in the same email or chat as the file.

Several files chosen together become several .enc files, all with the same password. To send a whole folder, zip it first (on iPhone: Files → select the items → More → Compress) and encrypt the zip.

Open the file (recipient)

  1. Save the .enc file from the email, chat or link to the phone or computer.
  2. Open clavisenc.com/open.html, tap Choose or drop .enc files and pick it.
  3. Enter the password they sent separately and tap Open. It's decrypted on the device; nothing is uploaded.
  4. Tap Save name to keep the original file, or View for a PDF, image or text file.

On a Windows or Linux PC, the recipient can also open it in the free Clavis Encrypt app, or with the open-source decryptor, because the .enc format is public.

Questions

How do I encrypt a file on my phone?

Open clavisenc.com/encrypt.html in your phone's browser, tap Choose or drop files, enter a password of at least 10 characters twice and tap Encrypt, then Save the .enc copy. It's encrypted on your phone with AES-256-GCM and nothing is uploaded. Send the password separately from the file.

Can I password protect a PDF on my iPhone?

Not with the built-in apps, unless you wrote the document in Pages: a Pages document's password carries over when you export it as a PDF. For a PDF you received, Adobe Acrobat's mobile app can add a password with a paid subscription, or you can lock it free at clavisenc.com/encrypt.html, which makes a locked .enc copy that opens in a browser with the password.

How do I password protect a file on Android?

Android's Safe folder (Files by Google) and Samsung's Secure Folder lock files on the phone, but files in them aren't locked when you send them. To lock a file for sending, encrypt it at clavisenc.com/encrypt.html in Chrome or another current browser, or make an AES-256 zip with a zip app.

How do I send a confidential document from my phone?

Encrypt it first, then send the locked copy by email, chat or a cloud link, and send the password a different way, such as a phone call. That way the document stays locked in the email or chat, on both phones and in their backups, and anyone who sees only one of the two messages can't open it.

Is it safe to encrypt a file on a website?

Only if the website encrypts on your device instead of uploading the file. clavisenc.com/encrypt.html runs in your browser, and its security policy stops it from connecting anywhere, so the file and password are never uploaded; it sends only a cookieless count with no file details. As with any web page, you're trusting the code the site sends you. The file format is public and its code hasn't been independently audited.

Is there a free way to encrypt a file online without uploading it?

Yes. clavisenc.com/encrypt.html is free, needs no account, and encrypts on your own phone or computer, so the file never leaves the device. Avoid services that ask you to upload a file to be encrypted on their server: they see it before it's locked.

Is WhatsApp safe for sending confidential documents?

WhatsApp encrypts files end to end while they travel, so WhatsApp can't read them on the way. Once delivered, the document is an ordinary file on both phones, and in chat backups unless end-to-end encrypted backups are turned on. Encrypting the document first keeps it locked everywhere it ends up.

Can the other person open the file on their phone?

Yes. They open clavisenc.com/open.html on any phone or computer, choose the .enc file, enter the password and tap Open; it's decrypted on their device. On a Windows or Linux PC they can also use the free Clavis Encrypt app.

What if I forget the password?

Then the file can't be opened by anyone. The password is never stored or sent anywhere, so there's nothing to recover it from. Keep your original file until the other person has opened theirs.
