Clavis Encrypt for teams

Client files, ID scans, payslips and contracts end up on every office PC and in every shared cloud folder. What a team gets

  • Team folders (Premium): one encrypted folder in OneDrive, Google Drive, Dropbox or a network drive that several people open, each with their own Clavis ID. No shared password. Members join free; editing a file in place needs Pro. How team folders work.
  • Find sensitive files (Pro): helps you find ID, bank, salary and tax documents left on a PC, then encrypt the ones you choose. It can miss some.
  • Whole folders and watch folders (Pro): encrypt a client folder in one step, or encrypt every new file saved into a folder automatically.
  • Sharing by Clavis ID (Premium): encrypt a file for one colleague or client; opening it is free for them.
  • Command line (Premium, installer version): scripted and scheduled encryption, for example for backups.
  • Free on every plan: the same AES-256-GCM encryption, the recovery key, Send with a password, and Shred (best effort on SSDs and USB sticks).

Rolling it out

  1. Install on each PC from the download page. The installer works per user and needs no administrator rights. For silent installs, run Clavis-Setup.exe /quiet /norestart. The Microsoft Store version also works, but it has no File Explorer right-click menu and no command line.
  2. Each person creates their own vault and password, and saves their recovery key somewhere safe.
  3. Paste each licence key into Settings → License. To move a licence to a new PC, choose Remove license on the old one first.
  4. For a shared folder, one person with Premium creates the team folder and adds colleagues by their Clavis ID. Add a second owner.

Honest limits

  • There is no central admin console: each licence key is activated on the PC itself.
  • There is no master key. If someone forgets their password and loses their recovery key, nobody can open their files, including us. In a team folder, add a second owner.
  • One licence can own up to 3 team folders; a team can have up to 10 members and 3 owners.
  • Clavis encrypts files, not whole drives. Keep BitLocker or Device Encryption on as well.
  • Windows 10 and 11, and Linux. There is no Mac or phone app; on those, encrypted files open in the browser at clavisenc.com/open.html.
  • Clavis Encrypt is closed source and hasn't been independently audited. Its file format is public, with an open-source decryptor. It can be part of how you protect personal data, but it doesn't make you compliant with any law on its own.

Questions

Do we need one licence per person or per PC?

One licence per person is usually right: each licence works on up to two PCs, for example an office PC and a laptop.

Does it need administrator rights to install?

No. The installer from the download page installs per user without administrator rights, and it supports silent installs with /quiet /norestart.

Can we manage licences centrally?

Not yet. Each key is activated on the PC in Settings → License, and Remove license frees it for another PC.

What happens if an employee forgets their password?

They can unlock their vault with their recovery key. There is no master key, so make sure everyone saves their recovery key, and add a second owner to team folders.

Does it work with OneDrive, Google Drive, Dropbox or a network drive?

Yes. Encrypted files stay encrypted in any synced folder, and team folders work in OneDrive, Google Drive, Dropbox or a network drive.
