How to encrypt files in Windows 11 Home (no BitLocker needed)

You right-click a folder, open Properties → Advanced, and “Encrypt contents to secure data” is greyed out. You search for BitLocker and it isn't there. That's not a bug: Microsoft keeps BitLocker and EFS (the Encrypting File System behind that checkbox) for Windows 11 Pro, Enterprise and Education. Most laptops ship with Windows 11 Home, so most people can't use either.

You can still protect your files. Here are the real options on Windows 11 Home, what each one actually protects, and how to choose.

Short answer: to encrypt files in Windows 11 Home, use two layers. For the disk, turn on device encryption if your PC has it (Settings → Privacy & security → Device encryption): it's Windows 11 Home's built-in disk encryption, based on BitLocker, and it protects a lost or stolen laptop. For individual files, which device encryption doesn't protect once you're signed in, use a password-protected 7-Zip archive (AES-256), a VeraCrypt container, or a file-encryption app such as Clavis Encrypt: right-click a file → Clavis → Encrypt, free, no administrator rights. Windows 11 Home has no BitLocker tool and no EFS; on a Windows 11 Home PC, even cipher /e answers “The request is not supported.”

Option 1: device encryption (Windows 11 Home disk encryption)

Many PCs running Windows 11 Home have device encryption, which Microsoft describes as “a Windows feature that enables BitLocker encryption automatically”. Open Settings → Privacy & security → Device encryption. If you see the page, you can turn it on. If you don't, your PC's hardware may not support it, or you're signed in with a standard account.

  • Good: free, built in, encrypts the internal drive. If the laptop is stolen while it's off, the thief can't read the disk in another machine.
  • Catch: it needs supported hardware and a Microsoft account (with only a local account it isn't turned on automatically), and it protects the drive, not your files. Once you're signed in, every file is open to anyone using the PC, and a copy you put on a USB stick or in the cloud isn't encrypted. Your recovery key is stored in your Microsoft account.

The full comparison, and how to check your PC in System Information, is in device encryption vs BitLocker on Windows 11 Home.

Option 2: a password-protected 7-Zip archive

Install the free 7-Zip, right-click the files → 7-Zip → Add to archive, choose the 7z format, set a password and tick Encrypt file names. It uses AES-256. (Windows' own Compress to ZIP file has no password option.)

  • Good: free and works on every edition of Windows.
  • Catch: you extract the archive every time you want to use a file, and decrypted copies are easy to leave behind. If you forget the password, there's no way back in.

Option 3: VeraCrypt

VeraCrypt creates an encrypted container that you mount like a drive. It's free, open source and very strong.

  • Good: excellent security and works on Windows 11 Home.
  • Catch: it needs administrator rights to install, you decide the container's size in advance, and you mount and unmount it each time. It's built for experts, and a lost password can't be recovered.

Option 4: an app that encrypts files directly

A file-encryption app like Clavis Encrypt locks individual files where they are. There's nothing to mount and no archive to extract, and it works the same on Home and Pro. Clavis installs without administrator rights and gives you a recovery key in case you forget your password.

To encrypt files with Clavis on Windows 11 Home:

  1. Download Clavis and run the installer. No administrator prompt appears.
  2. Create your vault with a strong password, then write down or print the recovery key it shows you.
  3. In File Explorer, select one file or several, right-click → Show more options → Clavis → Encrypt. Or drag them onto the Clavis window, choose Encrypt and press Encrypt now.
  4. Check the list Clavis shows you and confirm.

Each file becomes a .enc file with a random name, sealed with AES-256-GCM. To get it back, select it, choose Decrypt and press Decrypt now. Questions

How do I encrypt files in Windows 11?

On Windows 11 Pro, Enterprise or Education you can use EFS (right-click, Properties, Advanced, Encrypt contents to secure data) or BitLocker for whole drives. On Windows 11 Home, turn on device encryption for the disk if your PC has it, and encrypt individual files with a 7-Zip archive, a VeraCrypt container or a file-encryption app such as Clavis Encrypt.

Does Windows 11 Home have disk encryption?

Often, yes: device encryption, on supported hardware. It's BitLocker turned on automatically when you sign in with a Microsoft account, and it encrypts the internal drive. Check Settings, Privacy & security, Device encryption. Windows 11 Home doesn't have the full BitLocker tool.

Does Windows 11 Home have BitLocker?

No. The BitLocker tool and EFS (Encrypt contents to secure data) are only in Windows 11 Pro, Enterprise and Education. Many Home PCs have device encryption instead, which encrypts the whole drive with fewer settings.

Why is Encrypt contents to secure data greyed out in Windows 11?

Usually because the PC runs Windows 11 Home, which doesn't include EFS. On Pro, it can also be greyed out on drives that aren't NTFS (such as FAT32 or exFAT USB sticks) or when a policy turns EFS off. On Home, use device encryption for the disk and a file-encryption tool for files.

Is device encryption the same as BitLocker?

It's BitLocker's own encryption, turned on automatically with fewer controls. It covers the internal drives, only on supported hardware, and saves the recovery key to your Microsoft account. Full BitLocker adds per-drive control, a startup PIN and USB encryption.

Can I password-protect a folder on Windows 11 Home?

Not with a built-in tool. You can put the folder in a password-protected 7-Zip archive, keep it in a VeraCrypt container, or encrypt its files with Clavis (select all the files and encrypt them at once, free). Clavis Pro encrypts a whole folder, subfolders included, in one step.
