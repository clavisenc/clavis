How to encrypt files before emailing them

A tax return for your accountant, a passport scan for a landlord, a contract for a lawyer — email is how these things travel, and email is not a safe place for them. Attachments sit in your Sent folder, the recipient's inbox, and every backup of both, often for years. If any of those accounts is ever compromised, the files go with it.

Encrypting the file before you attach it means the email only ever carries a locked file. Here are five ways to do that, and the one rule that matters for all of them.

The one rule: never send the password in the same email

If the password travels with the file, anyone who gets the email gets both. Send the password another way — a text message, a phone call, a messaging app — or agree on it in person. Better still, use a method that needs no shared password at all (option 5).

Option 1: a password-protected 7-Zip archive

Install the free 7-Zip, select the files → 7-Zip → Add to archive, choose 7z, set a password and tick Encrypt file names. Attach the .7z file.

  • Good: free, strong (AES-256) and works for any kind of file.
  • Catch: the recipient needs 7-Zip or a similar tool — Windows' built-in zip support can't open it — and you still have to get the password to them safely.

Option 2: password-protect the document itself

Word, Excel and PowerPoint can encrypt a file with a password: File → Info → Protect Document → Encrypt with Password. PDFs can be password-protected with a PDF editor — see how to password-protect a PDF on Windows.

  • Good: the recipient opens it in an app they already have.
  • Catch: only works for those file types, and the password still has to travel separately.

Option 3: your email service's encryption

Some services can encrypt the message itself. Microsoft 365 business plans have an Encrypt button in Outlook, and services such as Proton Mail encrypt messages end to end.

  • Good: no extra tools if you already have the right plan.
  • Catch: it depends on your provider and plan, the recipient often has to open the message in a web portal, and the attachment usually isn't encrypted once it's downloaded. Note that Gmail's confidential mode is not encryption: it stops forwarding and can set an expiry date, but Google can still read the contents.

Option 4: a locked copy that opens in any browser (free)

If the recipient won't install anything, Clavis can lock a copy for them with a one-time password:

  1. Right-click the file (or a file you've already encrypted) → Show more options → Clavis → Send with a password…
  2. Clavis makes a copy named after the original, such as Tax return 2025.pdf.enc, and suggests a strong password like X4MQ6-6ZASS-2WX5A-ZHPKJ. Your original stays as it is.
  3. Attach the copy and paste the ready-made message. Your recipient opens it at clavisenc.com/open.html on a phone or any computer: it's decrypted on their device and nothing is uploaded.
  4. Send the password separately, by text or a call.

Sending from a phone? The same locked copy can be made in the browser at clavisenc.com/encrypt.html; see how to encrypt a file on your phone and send it safely.

  • Good: free, nothing for the recipient to install, works on phones, and the file name is part of the locked copy rather than the email.
  • Catch: like any password method, the password still has to reach them safely.

Option 5: encrypt the file for one person, with no password

With public-key encryption, you lock a file so only one specific person can open it. There's no password to send, so there's nothing to intercept. This is how Clavis sharing works:

  1. The recipient installs Clavis (free) and sends you their Clavis ID — a small file that's safe to share.
  2. You add it to your contacts, then right-click the file → Show more options → Clavis → Encrypt for someone… and pick them.
  3. Attach the .enc file to your email. Only their Clavis can open it, and it's signed by you, so they know it really came from you.

Questions

Is email encrypted already?

Usually only in transit between mail servers. The message and its attachments are stored readable in both mailboxes and their backups, so anyone who gets into either account can open them. Encrypting the file before you attach it closes that gap.

Is Gmail confidential mode encrypted?

No. Confidential mode can block forwarding, copying and downloading and can make a message expire, but it doesn't encrypt the contents, and Google can still read them. Encrypt sensitive attachments before sending.

How do I send the password safely?

Never in the same email. Use a different channel — a text message, a phone call or a messaging app — or agree on it in person. Or use public-key sharing such as Clavis, which needs no shared password.

Can I email an encrypted file to someone who doesn't use Clavis?

Yes. Use Send with a password (free): they open the file at clavisenc.com/open.html on a phone or computer, with the password you send separately. For Clavis sharing, which needs no password, they need Clavis, which is free to install and free for opening files shared with them.
