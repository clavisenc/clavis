OSV vs FDV vs RDV: BitLocker's operating system, fixed data and removable data volumes

BitLocker sorts every drive into one of three types: the operating system drive, fixed data drives and removable data drives. You'll see them shortened to OSV, FDV and RDV in help threads about recovery keys, and Microsoft's Group Policy registry values use similar prefixes: OS, FDV and RDV. The type decides how a drive unlocks and which settings apply to it; each encrypted drive still has its own recovery key, matched by its Key ID. Here's what each label means, where the labels appear, how to see which type each of your drives is, and what Windows 11 Home covers.

Short answer: OSV (operating system volume) is the drive Windows is installed on, normally C:. FDV (fixed data volume) is any other internal drive or partition, such as D:. RDV (removable data volume) is a USB stick, SD card or external disk encrypted with BitLocker To Go. Each encrypted drive has its own 48-digit recovery key: pick it by Key ID, not by label. Device encryption on Windows 11 Home covers OSV and FDV, not RDV.

What OSV, FDV and RDV stand for

The V stands for volume: BitLocker encrypts whole volumes, which you see as drives such as C: and D:. Microsoft organises its BitLocker settings the same way, into the operating system drive (“the drive where Windows is installed”), fixed data drives (“any local drives, except the operating system drive”) and removable data drives. One detail: Microsoft's Group Policy registry values shorten the operating system drive to OS, not OSV, for example OSRecovery next to FDVRecovery. The long forms appear in Microsoft Graph, which records each work or school recovery key's volume type as operatingSystemVolume, fixedDataVolume or removableDataVolume.

Where you see these labels

  • Manage BitLocker (Control Panel), on Windows 11 Pro, Enterprise and Education, lists drives under Operating system drive, Fixed data drives and Removable data drives - BitLocker To Go. Microsoft says it sorts them “based on how the device reports itself to Windows”, and only formatted drives with a drive letter appear properly.
  • Group Policy has a folder for each type under Computer Configuration → Administrative Templates → Windows Components → BitLocker Drive Encryption: Operating System Drives, Fixed Data Drives and Removable Data Drives. The registry values behind those policies use the short forms, such as OSRecovery, OSEncryptionType, FDVRecovery, FDVEncryptionType, FDVDenyWriteAccess, RDVConfigureBDE, RDVEncryptionType and RDVDenyWriteAccess.
  • Intune takes its BitLocker settings from the BitLocker CSP, which spells the types out as SystemDrives, FixedDrives and RemovableDrives, for example SystemDrivesRecoveryOptions, FixedDrivesRequireEncryption and RemovableDrivesConfigureBDE.
  • Work and school recovery keys backed up to Microsoft Entra ID carry a volume type in Microsoft Graph: operatingSystemVolume, fixedDataVolume or removableDataVolume.
  • PowerShell and manage-bde only split drives into two kinds. Get-BitLockerVolume shows VolumeType as OperatingSystem or Data, and manage-bde -status reports each volume as operating system or data (Microsoft's example marks C: as [OS Volume]). Neither tells fixed and removable data drives apart.
  • Your Microsoft account's recovery keys page (aka.ms/myrecoverykey): Microsoft doesn't document what the labels on this page mean. If you see OSV, FDV or RDV next to a key there, read them as the same three drive types, and still choose the key by its Key ID.

Microsoft notes that the TPM protector can only be used with the operating system drive. That's why the Windows drive can open at startup without you doing anything, while data drives rely on a password, a smart card or auto-unlock. Auto-unlock keeps its keys on the Windows drive: once that drive is unlocked, BitLocker uses information stored in the registry and in each data drive's metadata to unlock the data drives set to unlock automatically.

Which recovery key each drive needs

Recovery works drive by drive. Microsoft sets recovery options separately for operating system, fixed and removable drives, and Microsoft Graph ties each work or school recovery key to one volume type. The screen that asks for a key shows a Key ID: use the key with the matching ID, whatever label sits next to it.

  • OSV: Windows can ask at startup when something BitLocker checks has changed, such as a BIOS/UEFI firmware change made outside Windows Update without suspending BitLocker, the TPM being turned off or cleared, or the drive being moved to another computer. Microsoft says its own updates, including Windows quality and feature updates, need no BitLocker action from you.
  • FDV: moved to another computer, a fixed data drive opens with its password or smart card in the BitLocker Drive Encryption Control Panel. If it was set to unlock automatically only, Microsoft says it needs its recovery key.
  • RDV: you need the recovery key if you've forgotten the drive's password or can't use its smart card.

What Windows 11 Home covers

Windows 11 Home has no BitLocker tool: Microsoft says BitLocker Drive Encryption isn't available on Home. Many Home PCs have device encryption instead, which turns BitLocker on automatically for the operating system drive and fixed drives, so your OSV and any FDV. It doesn't encrypt external or USB drives, and you can't make an RDV on Home, because turning BitLocker on needs Pro, Enterprise or Education. Device encryption only protects the drives once an administrator signs in with a Microsoft account, or you sign in with a work or school account; with only local accounts, the drives aren't protected. More on the difference: device encryption vs BitLocker on Windows 11 Home. For a USB stick on Home, see how to encrypt a USB drive on Windows 11 Home.

How to check which type each drive is

  1. Settings (Home and Pro): open Start → Settings → Privacy & security → Device encryption. It shows whether device encryption is on, but not drive types. Microsoft notes it doesn't show device encryption as on until encryption is complete. If the page is missing, device encryption isn't available on the PC or you're signed in with a standard account.
  2. Manage BitLocker (Pro, Enterprise and Education): select Start, type BitLocker and select Manage BitLocker. The drive under Operating system drive is your OSV, drives under Fixed data drives are FDVs, and drives under Removable data drives - BitLocker To Go are RDVs. If Manage BitLocker isn't listed, Microsoft says you don't have the right Windows edition.
  3. Command line: right-click Start, choose Terminal (Admin) and run manage-bde -status. Each volume shows its encryption and protection status, and the Windows drive is marked [OS Volume]. In PowerShell, Get-BitLockerVolume shows VolumeType (OperatingSystem or Data) and AutoUnlock Enabled. On Windows Home, Microsoft doesn't say whether manage-bde works; if it gives an error, use Settings.

Questions

What is an OSV drive?

OSV stands for operating system volume: the drive Windows is installed on, normally C:. With BitLocker it's the drive that unlocks at startup, by default automatically with the PC's TPM chip, or with a PIN or startup key if one was set up. Microsoft's settings call it the operating system drive.

What is an FDV drive?

FDV stands for fixed data volume: an internal drive or partition that isn't the Windows drive, such as D: or a second SSD. A BitLocker-protected FDV unlocks with a password or smart card, or automatically once the Windows drive is unlocked if auto-unlock is on. Device encryption on Windows 11 Home covers fixed drives too.

OSV vs FDV: which one is my C: drive?

C: is normally the OSV, because it's the drive Windows is installed on; Microsoft's manage-bde example shows C: as [OS Volume]. Other internal drives and partitions, such as D:, are FDVs. To check, open Manage BitLocker on Pro, where the Windows drive is listed under Operating system drive, or run manage-bde -status in Terminal (Admin).

Is a USB stick an RDV?

Usually. RDV means removable data volume, and Microsoft's examples are USB flash drives, SD cards and external hard disks, encrypted with BitLocker To Go. Windows sorts each drive by how the device reports itself, so check which list a particular external drive appears under in Manage BitLocker. Device encryption doesn't encrypt USB drives.

What do OSV and FDV mean on my BitLocker recovery keys page?

OSV is short for operating system volume (the drive Windows runs from) and FDV for fixed data volume (another internal drive); RDV is a removable data volume. Microsoft doesn't document the labels on that page, so don't pick a key by its label: use the one whose Key ID matches the ID on the screen asking for it. Full steps: how to find your BitLocker recovery key.

Does device encryption encrypt FDV and RDV drives?

FDV yes, RDV no. Microsoft says device encryption turns BitLocker on automatically for the operating system drive and fixed drives, and doesn't encrypt external or USB drives. To encrypt a removable drive as a whole you need BitLocker To Go on Windows Pro, Enterprise or Education, or another tool.

Why is my FDV drive asking for a recovery key?

Because it can't unlock the normal way. Automatic unlocking of a fixed data drive needs the Windows drive on the same PC to be BitLocker-protected. Moved to another computer, a fixed data drive opens with its password or smart card, and if it was set to unlock automatically only, Microsoft says you need its recovery key. Use the key whose Key ID matches the prompt.
