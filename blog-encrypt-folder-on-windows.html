How to password protect (encrypt) a folder in Windows 11 Home or Pro

You want a folder that asks for a password before anyone can open it: tax returns, ID scans, contracts, private photos. Windows doesn't have that switch. On Pro, the encryption option in a folder's Properties uses your Windows sign-in instead of a password, and on Home it's greyed out. Many how-tos fill the gap with a batch file that only hides the folder. Here's what really locks a folder on Windows 11 Home (and Pro), what only hides it, and what happens if you forget the password.

Short answer: no edition of Windows 11 has a setting that puts a password on a folder. On Pro, Enterprise or Education, Encrypt contents to secure data (EFS) encrypts a folder, but it's tied to your Windows sign-in, not a separate password. On Windows 11 Home, including Home Single Language, that option is greyed out because Home doesn't include EFS. What works on Home: put the folder in a 7-Zip archive with a password (7z format, AES-256, Encrypt file names ticked); keep a few files in OneDrive Personal Vault, which unlocks with a PIN, fingerprint, face or a code; make a VeraCrypt container; or encrypt the folder's files with an app such as Clavis Encrypt, which keeps each file encrypted wherever it's copied and gives you a recovery key. Hidden folders and Locker.bat “folder lock” scripts only hide files: anyone can still open them. BitLocker and device encryption protect the whole drive, not one folder.

First, check your edition of Windows

Open Settings → System → About and look next to Edition under Windows specifications.

  • Windows 11 Home or Windows 11 Home Single Language: no EFS and no BitLocker. Use options 1 to 4 below. Microsoft describes Home Single Language as the edition where only one display language can be installed; everything this guide says about Home applies to it.
  • Windows 11 Pro, Enterprise or Education: you also have EFS (option 5) and BitLocker. Options 1 to 4 work too, and they're the ones with a real password.
  • Windows 11 Home in S mode: Microsoft says S mode “only works with compatible apps from Microsoft Store” and that switching out of it “is one-way”. So 7-Zip and VeraCrypt from their websites, and the direct-download Clavis installer, won't install until you switch out of S mode. Microsoft's S mode FAQ explains how.

1. A password-protected 7-Zip archive (Home or Pro, free)

  1. Install the free 7-Zip.
  2. Right-click the folder → Show more options (Windows 11) → 7-Zip → Add to archive…
  3. Set Archive format to 7z, enter a password twice, keep the encryption method at AES-256 and tick Encrypt file names.
  4. Press OK. Open the new .7z file and check that it asks for your password and that your files are inside.
  5. Only then delete the original folder and empty the Recycle Bin. Don't skip the check: if the password was mistyped, the archive is the only copy left.

Why not Windows' own zip? Windows 11 version 24H2 can compress and decompress several archive formats, including 7z, but Microsoft says it “does not support operations on encrypted archive files” and points you to non-Microsoft apps such as 7-Zip or WinRAR. Windows' Send to → Compressed (zipped) folder has no password option. If you don't want an archive at all, use options 2 to 4.

  • Good: free and open source, works on Windows 10 and 11, strong encryption, and one file is easy to copy, email or put on a USB stick.
  • Catch: it's a locked copy, not a locked folder. To use a file you extract it, and extracted copies are easy to forget on the PC. After every change you re-pack the archive. Deleting the originals is best effort on SSDs and USB sticks: see what deleting really does on Windows 11.

2. OneDrive Personal Vault: Microsoft's closest thing to a locked folder

Personal Vault is a protected folder inside OneDrive. It's the closest thing Windows has to a folder that asks for something before it opens.

  1. Sign in to OneDrive with a personal Microsoft account, open your OneDrive folder and open Personal Vault (or select Get started on the Personal Vault message). Microsoft also describes turning it on at OneDrive.com, under Settings → Personal Vault → Enable. You set it up separately on each device where you use it.
  2. Select Next or Continue (it depends on the device), then in Verify your identity select Verify and choose how to verify, such as a text message.
  3. Move the files you want to protect into it.
  4. From then on it unlocks with your fingerprint, face or PIN, or a code sent by email or SMS. It locks itself after a period of inactivity; on Windows you choose how long in OneDrive's settings, on the Account tab. You can also lock it at any time.
  • Limits, from Microsoft's own page: Microsoft says Microsoft 365 Basic, Personal and Family subscribers can now add as many files as their storage allows, and its FAQ says that without a Microsoft 365 subscription you can add up to three files. It's offered to personal OneDrive users (Basic, Personal and Family). Sharing files from it is blocked: you have to move a file out to share it. After you open a file, its name might appear in that app's Recent list.
  • Catch: the files live in OneDrive, so they're stored in Microsoft's cloud, and the vault is only as safe as your Microsoft account's sign-in. It's not a password on a folder of your choice.

3. A VeraCrypt container (Home or Pro, admin rights)

VeraCrypt creates an encrypted file that you mount as a drive letter; anything you put in it is encrypted. It's free, open source and strong, and works on Home. The catches: installing it needs administrator rights, you choose the container's size up front, you mount and unmount it each time (while it's mounted, it's open), and a lost password can't be recovered.

4. Clavis Encrypt (Home, no admin rights)

Clavis Encrypt is our app. It encrypts the files in a folder where they are, with AES-256-GCM, and gives each encrypted file a random name, so even file names give nothing away. It doesn't hide or “lock” the folder itself: the folder stays where it is, but every file in it becomes an .enc file that opens only with your password. No account, nothing uploaded.

  1. Install Clavis (Windows 10 or 11, no administrator prompt) and create your vault. Write down or print the recovery key it shows you before you encrypt anything: it's your way back in if you forget your password.
  2. Free: open the folder, select its files (Ctrl+A), right-click → Show more options → Clavis → Encrypt. Clavis lists them and asks you to confirm once. Free encrypts files, not folders: if there are subfolders, leave them out of the selection and encrypt their files from inside each one, or use Clavis Pro to do them all in one step. The right-click menu comes with the direct-download installer; in the Microsoft Store version, drag the files onto the Clavis window instead.
  3. Pro ($19 once): right-click the folder itself → Show more options → Clavis → Encrypt, or drag the folder onto the Clavis window, choose Encrypt and press Encrypt now. Every file, subfolders included, is encrypted in one step. Pro can also watch a folder, so new files saved or downloaded into it are encrypted automatically.
  4. To get the files back, choose the folder, select Decrypt and press Decrypt now. Decrypting a whole folder is free.
  • Good: works on Home without admin rights; each file stays encrypted wherever you copy it (a USB stick, an email, OneDrive); there's a recovery key, and Windows Hello unlock is free.
  • Catch: the app is closed source and hasn't been independently audited (the file format is public, with an open-source decryptor). It's for Windows and Linux only. It doesn't encrypt the whole drive, so keep device encryption or BitLocker on too. The originals are overwritten and deleted after encrypting, but on SSDs and USB sticks that's best effort.

5. On Windows 11 Pro: EFS (“Encrypt contents to secure data”)

  1. Right-click the folder → Properties, then select Advanced….
  2. Tick Encrypt contents to secure data, select OK, then Apply.
  3. In Confirm Attribute Changes, choose Apply changes to this folder, subfolders and files → OK, then select OK again to close Properties.
  4. Back up your EFS certificate and key before you rely on it, and keep the backup off the PC. From Command Prompt, cipher /x E:\efs-key-backup backs them up to a file, where E: is a USB stick or another drive that isn't the PC's own.
  • Good: built in and invisible once set up. Files you add to the folder later are encrypted too.
  • Catch: it never asks for a password. Encryption is tied to your Windows account, so anyone signed in as you opens the files normally, and if you lose the account without a key backup, you can lose the files. It works only on NTFS drives, so copies on most USB sticks, in email or in cloud storage aren't encrypted.

On Home the option is greyed out because Home doesn't include EFS: Microsoft says “File encryption is not available in the Home edition of Windows.” For the other causes and a quick test, see why Encrypt contents to secure data is greyed out.

6. What doesn't protect a folder

  • The Locker.bat “command prompt” folder lock. We tried the batch file that many how-tos share, on Windows 11 Home. It encrypts nothing: it renames the folder and marks it hidden. In Command Prompt, dir /a still listed the “locked” folder, a file inside opened without the password, and cipher reported it as unencrypted. The password itself is written in plain text inside the .bat file, so anyone who opens it in Notepad can read it. We don't reproduce the script here.
  • The Hidden attribute. Anyone can show hidden folders: Microsoft's own File Explorer help says to select View → Show → Hidden items.
  • Folder permissions. Taking other accounts off a folder's permissions can keep other standard users out, but Microsoft notes that administrators “have complete control over the system”, and permissions don't travel with a copy or protect a drive taken out of the PC.
  • Backups. A backup is another copy. If the folder is private, its backups need protecting too.

7. BitLocker and device encryption: whole drives, not folders

BitLocker “isn't available on Windows Home edition,” Microsoft says. Device encryption is, on supported PCs: check Settings → Privacy & security → Device encryption. Both encrypt the whole drive, which is the right protection for a lost or stolen laptop, so turn one on. But neither is a folder password. Once you're signed in, every folder is open as normal, and copies you make elsewhere aren't encrypted. Device encryption vs BitLocker explains the difference, and if the Device encryption page is missing, see why device encryption isn't available.

8. A shared family PC: separate accounts first

If the people you're hiding a folder from use the same PC, give each person their own Windows account. Microsoft describes separate accounts as a way of “keeping family members' data private and secure from each other”, and recommends standard accounts for day-to-day use. That keeps others out of your user folders while they're signed in as themselves, but it adds no folder password, and an administrator can still reach your files. For the full setup, see how to keep files private on a shared family PC.

Which should you use?

  • Sending or archiving a folder once? A 7-Zip archive.
  • A few documents, and you already use OneDrive? Personal Vault.
  • Admin rights, and you don't mind mounting a drive? VeraCrypt.
  • A working folder on Home that stays encrypted wherever it's copied, with a recovery key? A file-encryption app like Clavis.
  • On Pro, and only you use the account? EFS, as long as you back up the key.
  • Everyone: device encryption or BitLocker as well, for the whole drive.

Only need to protect a few files rather than a folder? See how to encrypt files on Windows 11 Home. Carrying the folder on a stick? See how to encrypt a USB drive on Windows 11 Home.

What can go wrong

  • You forget the password. With 7-Zip and VeraCrypt, nobody can get the files back. Save the password in a password manager before you delete any originals. With Clavis, keep the recovery key somewhere other than the PC. With EFS, keep the key backup you made with cipher /x (option 5, step 4).
  • Unencrypted copies stay behind. The original folder, extracted copies, old versions in a cloud service's version history or recycle bin, and backups can all still hold readable files. Find and remove them; on SSDs and USB sticks, deleting is best effort.
  • The option is greyed out. On Home that's expected: use options 1 to 4. On Pro, check that the drive is NTFS and that no policy turns encryption off; why Encrypt contents to secure data is greyed out covers the other causes.
  • Personal Vault won't take more files. Microsoft's FAQ says that without a Microsoft 365 subscription you can add up to three files.
  • The VeraCrypt drive is left mounted. Until you dismount it, its files are open to anyone at the PC.

On Windows 10

The answer is the same. Windows 10 Home has no EFS and no BitLocker; on Windows 10 Pro, the Properties → Advanced → Encrypt contents to secure data steps above work the same way. 7-Zip, Personal Vault, VeraCrypt and Clavis all run on Windows 10, and its right-click menu shows 7-Zip and Clavis directly, without Show more options. Questions

Can you password protect a folder in Windows 11 Home?

Not with a built-in setting. No edition of Windows puts a password on a folder, and Windows 11 Home has neither EFS nor BitLocker. On Home, use a 7-Zip archive with a password, OneDrive Personal Vault for a few files, a VeraCrypt container, or a file-encryption app such as Clavis Encrypt.

Can you encrypt a folder in Windows 11 Home?

Not with Windows' own tools: Microsoft says file encryption is not available in the Home edition, so Encrypt contents to secure data is greyed out. Use a 7-Zip archive (7z, AES-256, Encrypt file names ticked), a VeraCrypt container, or Clavis Encrypt, which encrypts the files you select in a folder for free, or the whole folder with subfolders in Clavis Pro.

Why can't I password protect a folder in Windows 11?

Windows has no folder-password feature in any edition. Its built-in folder encryption, EFS, uses your Windows sign-in instead of a password, and on Home it's greyed out because Home doesn't include EFS. Our page on why Encrypt contents to secure data is greyed out covers the other causes.

How do I lock a folder in Windows 11 Home Single Language?

The same way as on Windows 11 Home: Microsoft describes Home Single Language as the edition that allows only one display language. Use a 7-Zip archive with a password, OneDrive Personal Vault, a VeraCrypt container or a file-encryption app such as Clavis Encrypt.

Can I password protect a folder without software?

Not with a real password. On Pro, EFS encrypts a folder without extra software, but it uses your Windows sign-in, and Home doesn't have it. If you use OneDrive, Personal Vault adds a locked folder, but it unlocks with a PIN, fingerprint, face or code, and Microsoft's FAQ says it takes up to three files without a Microsoft 365 subscription.

Can Windows make a password-protected ZIP by itself?

No. Windows 11 can compress and decompress several archive formats, but Microsoft says it does not support operations on encrypted archive files and suggests non-Microsoft apps such as 7-Zip or WinRAR. The Compressed (zipped) folder option has no password setting.

Is the Locker.bat folder lock safe?

No. It doesn't encrypt anything: it renames and hides the folder. In our test on Windows 11 Home, dir /a still listed the folder and a file inside opened without the password. The password is stored in plain text in the .bat file, so anyone can read it in Notepad.

Does BitLocker or device encryption lock a folder?

No. Both encrypt a whole drive. They protect a laptop that's lost or stolen while it's switched off, but once you're signed in every folder is open as normal. BitLocker isn't available on Home; device encryption is, on supported PCs.

What happens if I forget the folder password?

It depends on the method. With 7-Zip or VeraCrypt the files can't be recovered. With Clavis Encrypt you get back in with the recovery key you saved when you set it up. EFS files open again only with a backup of your EFS key, and Personal Vault depends on your Microsoft account's sign-in.

How do I password protect a folder on Windows 10?

The same way as Windows 11. Windows 10 Home has no built-in option, so use 7-Zip, OneDrive Personal Vault, VeraCrypt or an app such as Clavis Encrypt. On Windows 10 Pro, Encrypt contents to secure data (EFS) encrypts a folder, tied to your Windows sign-in rather than a password.
