Add a key file as a second factor

A key file is a second factor: the vault then needs your password and that exact file. Someone who learns your password still can't open your files without it. Keep the key file on a USB stick you carry, and the vault only opens when the stick is plugged in.

  • Choose the key file when you create the vault. Any file works — a photo, a document — as long as it never changes. Even one changed byte makes it a different key.
  • Keep a copy of the key file somewhere safe.
  • If you lose it, your recovery key still unlocks the vault.
