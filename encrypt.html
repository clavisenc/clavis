    How it works

    1. Choose one or more files and a password (or press Suggest a password).
    2. Each file is encrypted with AES-256-GCM on this device, with a key made from your password by Argon2id.
    3. Save the .enc file and send it any way you like: email, a chat app, a cloud link or a USB stick.
    4. Send the password a different way, such as a phone call or a different app, not with the file.
    5. They open it at Open an encrypted file on any phone or computer, or in the free Clavis Encrypt app.

    Good to know

    • Encrypting takes a few seconds per file: the same deliberate slowness that protects your password from guessing.
    • Up to 1 GB at a time on a phone and 2 GB on a computer: very large files may not fit in a phone's memory. The app has no such limit.
    • The .enc file keeps the original name (for example report.pdf.enc) so the other person knows what it is. If the name itself is private, rename the .enc file: the real name is stored inside, encrypted, and comes back when it's opened.
    • If the password is forgotten, the file can't be opened by anyone, including us. Keep your original until they've opened theirs.
    • It's the same public file format the Clavis Encrypt app writes, and an open-source decryptor opens it too. This page's code hasn't been independently audited (see Security).
    • For files you keep, whole folders, the right-click menu and automatic encryption, use the free Clavis Encrypt app for Windows (or Linux).

    Questions

    Is it safe to encrypt a file on a website?

    This page encrypts on your device. Its code runs in your browser, and the page's security policy stops that code from connecting anywhere, so the file and the password are never uploaded. As with any web page, you're trusting the code the site sends you. The file format is public, so you can check a file with the open-source decryptor. The code hasn't been independently audited.

    How does the other person open the file?

    At clavisenc.com/open.html on any phone or computer, where it's decrypted on their device, or in the free Clavis Encrypt app for Windows and Linux. They need the password you send them separately.

    How should I send the password?

    Separately from the file: a phone call, a text message or a different chat app, never in the same email or chat as the file. Anyone who gets both can open it.

    What encryption does it use?

    AES-256-GCM, with a key made from your password by Argon2id (64 MB of memory, 2 passes) and a new random salt for every file. The content is compressed, then sealed in 64 KB chunks, so a changed, reordered or cut-off file is detected when it's opened. It's the same .enc format the Clavis Encrypt app writes.

    Is there a size limit?

    Up to 1 GB at a time on a phone and 2 GB on a computer, because the browser holds the encrypted file until you save it. The Clavis Encrypt app has no such limit.

    Can I encrypt a folder?

    Not on this page. Zip the folder first and encrypt the zip file, or use the Clavis Encrypt app, which encrypts whole folders.

    Is it free?

    Yes. There's no account, no sign-up and no limit on how often you use it.

    What if I forget the password?

    Then the file can't be opened. The password is never stored or sent anywhere, so there's nothing to recover it from. Keep your original file until the other person has opened theirs.
