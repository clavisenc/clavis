How to check if your drive is encrypted on Windows 11

Many Windows 11 laptops encrypt their own drive during setup, and their owners often find out only when Windows asks for a recovery key at startup. Other people assume their PC is encrypted when it isn't. And some drives are encrypted but not protected, because the key that unlocks them is stored unprotected on the same disk. Here's how to check in Settings, Control Panel, Command Prompt and PowerShell, and what each result means.

Short answer: on Windows 11 Home or Pro, open Settings → Privacy & security → Device encryption; it shows On only once encryption has finished. On Pro, Enterprise or Education, Manage BitLocker in Start shows it too. For detail, run manage-bde -status C: in a terminal opened as administrator and read Percentage Encrypted (is the data encrypted?) and Protection Status (is the key locked away?). 100% with Protection On means encrypted and protected. With Protection Off, the key sits in the clear on the disk, so the drive isn't protected yet.

Check in Settings (Windows 11 Home and Pro)

  1. Sign in with an administrator account. Microsoft says the page may not appear if you're signed in with a standard account.
  2. Open Settings and select Privacy & security.
  3. Select Device encryption. On the PC itself, this link opens the page directly: ms-settings:deviceencryption.
  4. Read the switch: On or Off.

Microsoft says the Settings page doesn't show device encryption as enabled until encryption is complete. While Windows is still encrypting, the switch can't tell you how far it has got, so use manage-bde (below) to see the percentage.

If Device encryption isn't listed under Privacy & security at all, your PC doesn't support it, or you're signed in with a standard account. Device encryption not available on Windows 11 explains how to find the reason in System Information.

On Windows 10, press Windows key + R, type ms-settings:deviceencryption and select OK: Microsoft's support page that gives this shortcut covers both Windows 10 and Windows 11.

Check in Control Panel (Windows 11 Pro, Enterprise and Education)

  1. Select Start, type BitLocker and select Manage BitLocker. This opens the BitLocker Drive Encryption Control Panel.
  2. Find your drives. Microsoft says the applet sorts them into the Windows (operating system) drive, fixed data drives and removable data drives, based on how each drive reports itself to Windows.
  3. Read the status next to each drive letter.

Microsoft lists four statuses:

StatusMicrosoft's description
OnBitLocker is enabled for the volume.
OffBitLocker isn't enabled for the volume.
SuspendedBitLocker is suspended and not actively protecting the volume.
Waiting for ActivationBitLocker is enabled with a clear protector key and requires further action to be fully protected.

A drive shows up properly here only if it's formatted and has a drive letter. Microsoft lists BitLocker for Windows Pro, Enterprise and Education, not Home. On a Windows 11 Home PC we tested, Control Panel had no BitLocker Drive Encryption item (it listed one called Device Encryption instead). On Home, use Settings or manage-bde.

Check with manage-bde -status

manage-bde is the BitLocker command-line tool, and it shows the most detail. Device encryption is BitLocker turned on automatically, so you read both the same way. It needs a terminal opened as administrator. Microsoft lists BitLocker for Pro, Enterprise and Education, and its manage-bde reference doesn't say whether the command works on Home. On a Windows 11 Home PC we tested, manage-bde.exe was present, but we only ran it without administrator rights, and it refused (see below). If it doesn't work on your Home PC as administrator, use Settings.

  1. Open a terminal as administrator: right-click Start (or press Windows key + X) and choose Terminal (Admin). On some PCs it's called Windows Terminal (Admin) or Windows PowerShell (Admin). Select Yes when Windows asks whether to allow changes.
  2. Type manage-bde -status C: and press Enter. Leave out C: to see every drive.
  3. Read the lines explained below.

This is Microsoft's sample output for an encrypted, protected Windows drive:

  • Conversion Status: whether the drive is fully encrypted, fully decrypted, or being encrypted or decrypted, and whether that has paused. Encryption in Progress, Encryption Paused, Decryption in Progress and Decryption Paused mean Windows is part-way through. Microsoft's developer documentation says to rely on this state, not the percentage, to tell whether a drive is fully encrypted or fully decrypted. Used Space Only Encrypted, as in Microsoft's sample, means only the space that held data was encrypted; new data is encrypted as it's saved. Microsoft warns that files deleted before encryption sit in free space that this mode doesn't encrypt, and can be recovered until they're overwritten.
  • Percentage Encrypted: how far encryption or decryption has got. Use it to follow progress, and Conversion Status to see which way it's going.
  • Protection Status: the line that matters most. Protection On means the drive is fully encrypted and its key isn't available in the clear on the disk. Protection Off means the drive is unencrypted, partly encrypted, or its key is available in the clear on the disk.
  • Lock Status: Unlocked means Windows can read the drive right now. Locked means a data or USB drive hasn't been unlocked yet.
  • Key Protectors: what can unlock the drive. TPM is the PC's security chip. Numerical Password is the 48-digit recovery password (PowerShell calls it RecoveryPassword).

If you forget to run the terminal as administrator, you get an error instead. This is what manage-bde -status C: returned on a Windows 11 Home PC we tested, from a terminal not run as administrator (the version number on yours may differ):

Close it, open a terminal as administrator (step 1) and run the command again. If your account isn't an administrator, ask whoever manages the PC to run it.

Careful: -status only reads. Other manage-bde options change the drive. Never type -on to check: Microsoft documents it as "Encrypts the drive and turns on BitLocker." -off starts decrypting (Microsoft notes it doesn't ask you to confirm), and -protectors -disable suspends protection.

  • VolumeStatus: FullyEncrypted, FullyDecrypted, or a value saying encryption or decryption is in progress or paused, such as EncryptionInProgress.
  • ProtectionStatus: On or Off, with the same meaning as Protection Status above. Microsoft describes it as whether BitLocker currently uses a key protector to encrypt the drive's encryption key.
  • EncryptionPercentage: 0 to 100. Microsoft's developer documentation warns that, because of rounding, 0 or 100 doesn't always mean fully decrypted or fully encrypted. VolumeStatus is the one to trust.

It needs administrator rights too. On the Windows 11 Home PC we tested, it returned Access denied in a terminal not run as administrator.

Encrypted but not protected

BitLocker encrypts your data with a key, then locks that key with a protector, such as the PC's TPM chip. Protection Status tells you whether that lock is in place. A drive can be 100% encrypted with the lock off. There are three common ways to end up there.

Suspended. Microsoft says suspending "keeps the data encrypted", but the key is then protected by a clear key: "a cryptographic key stored unencrypted and unprotected on the disk drive". People and update tools suspend BitLocker on purpose before some firmware and BIOS updates, so the PC doesn't ask for the recovery key afterwards. If that's why, finish the update and restart. Protection comes back by itself after the number of restarts chosen when it was suspended, unless that number was 0 (see how suspending works). If it's still suspended, resume protection:

  • Pro, Enterprise or Education: in Manage BitLocker, select the Windows drive, then Resume protection.
  • From an administrator terminal, Microsoft's command for resuming: manage-bde -protectors -enable C: (in PowerShell, Resume-BitLocker -MountPoint "C:" does the same)

Don't resume in the middle of a firmware or BIOS update: Microsoft says applying those updates while BitLocker is protecting the drive can send the PC to the recovery screen at the next restart. Have your recovery key ready before you change anything.

Waiting for Activation. The drive was encrypted with only a clear key and was never given a proper protector. Device encryption starts in a similar state. After Windows setup, it encrypts the drive with a clear key, "the equivalent of standard BitLocker suspended state", and File Explorer shows a yellow warning icon on the drive. Microsoft's guide for PC makers says protection is armed only after someone signs in with a Microsoft account or a work or school account; until then, "data is not protected". When an administrator signs in with a Microsoft account, Windows removes the clear key, saves the recovery key to that account and creates the TPM protector.

On Pro, Enterprise or Education, Microsoft says an administrator can also add a protector from Manage BitLocker, PowerShell or manage-bde. Before you do, make sure the drive has a recovery password and that a copy is saved somewhere off the PC. Microsoft's own example of turning on BitLocker with only the TPM protector has "no recovery key", and Microsoft says that in recovery mode you need the recovery password or recovery key to unlock the drive.

  • In Manage BitLocker, select the drive and choose Back up your recovery key.
  • From an administrator terminal, manage-bde -protectors -add -recoverypassword C: adds a recovery password, and manage-bde -protectors -get C: lists the drive's protectors. Write down the 48-digit Numerical Password it shows (or save it with Manage BitLocker → Back up your recovery key) and keep it off the PC before you add any other protector.

Local accounts only. Microsoft describes this case in two ways. Its support page and its guide for PC makers say that with a local account, device encryption isn't turned on automatically. Its BitLocker overview says that a device that uses only local accounts "remains unprotected even though the data is encrypted". In practice, if you set up your PC without a Microsoft account, don't guess: run manage-bde -status C: and read Protection Status. If the drive is encrypted but says Protection Off, Microsoft says a PC that isn't joined to a work or school network needs a Microsoft account with administrator rights on it: when that administrator signs in with the Microsoft account, Windows removes the clear key, uploads the recovery key to the account and creates the TPM protector. Afterwards, check that the key appears at aka.ms/myrecoverykey. On Pro, Enterprise or Education, Microsoft's guide for PC makers adds that BitLocker can be turned on manually from the BitLocker Control Panel (Manage BitLocker). If Conversion Status says Fully Decrypted, see if it's off.

Wondering why Windows encrypted your drive by itself, or whether Windows 11 is encrypted by default? See how to turn off device encryption on Windows 11, which covers both.

Check an external or USB drive

Device encryption covers the Windows drive and other fixed internal drives, not external or USB drives. A USB stick is encrypted only if someone used BitLocker To Go (from a Pro, Enterprise or Education PC) or another tool. To check, plug it in, note its drive letter, and run manage-bde -status E: in an administrator terminal, using its letter instead of E:. On Pro, look for it in Manage BitLocker under removable data drives, or under fixed data drives if it isn't there: Microsoft says the applet sorts drives by how each one reports itself to Windows. If Lock Status says Locked, unlock the drive to see the rest. To lock a USB stick on Windows 11 Home, see how to encrypt a USB drive on Windows 11 Home.

If it's on: find your recovery key now

A firmware update, a hardware change or a repair can make Windows ask for the 48-digit recovery key at startup, and without it the drive stays locked. Microsoft says its support team can't retrieve, provide or recreate a lost key. For a personal Microsoft account, open aka.ms/myrecoverykey on another device (it goes to account.microsoft.com/devices/recoverykey) and find the key for this PC. If someone else set up the PC, it may be in their account. For the other places to look, see how to find your BitLocker recovery key on Windows 11.

If it's off: what to do next

Before you turn encryption on, make sure the recovery key will be saved somewhere you can reach from another device. Encrypting with no reachable recovery key is how people lock themselves out.

  1. Device encryption (Home and Pro, on supported PCs): sign in with an administrator account, open Settings → Privacy & security → Device encryption and turn the switch On. If you use a local account, sign in with a Microsoft account first so the recovery key is attached to it, then check that it appears at aka.ms/myrecoverykey.
  2. BitLocker (Pro, Enterprise and Education): select Start, type BitLocker, select Manage BitLocker, then Turn on BitLocker next to the drive. When asked, back up the recovery key to your Microsoft account, a USB flash drive, a file kept off the PC, or a printout.
  3. Neither is offered: see why device encryption isn't available for the usual reasons and fixes.

Questions

How do I know if my laptop is encrypted on Windows 11?

Open Settings, Privacy & security, Device encryption and see whether it's On. On Windows 11 Pro, Enterprise or Education, also search Start for Manage BitLocker. For the most detail, open a terminal as administrator and run manage-bde -status C:. Percentage Encrypted shows whether the data is encrypted, and Protection Status shows whether it's actually protected.

Why does it say Protection Off if my drive is 100% encrypted?

Because the key that unlocks the drive is stored in the clear on the disk. That happens when BitLocker is suspended, for example before a firmware update, or when device encryption has encrypted the drive but was never activated, which Microsoft says is the case until someone signs in with a Microsoft account or a work or school account. The data is encrypted, but the drive isn't protected until protection is resumed or a protector is added.

What does Waiting for Activation mean in BitLocker?

Microsoft says it means BitLocker is enabled with a clear protector key and requires further action to be fully protected. The drive is encrypted, but it isn't protected yet. On a PC with device encryption, signing in with a Microsoft account as an administrator removes the clear key, saves the recovery key to that account and adds the TPM protector.

Does manage-bde work on Windows 11 Home?

manage-bde.exe was present on the Windows 11 Home PC we tested. Without administrator rights it returned an access-denied error asking for administrative rights, so open a terminal as administrator first. Microsoft lists BitLocker for Pro, Enterprise and Education and doesn't say whether manage-bde -status works on Home, and we haven't tested it as administrator on Home. If it doesn't work there, use Settings, Privacy & security, Device encryption.

Does manage-bde show other encryption tools like VeraCrypt?

No. Microsoft describes Get-BitLockerVolume as getting information about "volumes that BitLocker Drive Encryption can protect", and manage-bde -status reports each drive's BitLocker state. Microsoft's developer documentation also says that on a hardware-encrypted drive, Protection Off can mean the drive is managed by a third-party key manager. So a drive that shows as not encrypted or not protected could still be encrypted by other software, such as VeraCrypt, or by a drive maker's own tool. Check in that tool instead.

Does checking BitLocker status change anything on my drive?

No. manage-bde -status and Get-BitLockerVolume only read the drive's status, and looking at the Settings or Manage BitLocker pages changes nothing unless you press a switch or button. Be careful not to type -on or -off instead of -status: those start encrypting or decrypting the drive.

Device encryption is in progress. How do I see how far it has got?

Run manage-bde -status C: from a terminal opened as administrator and read Percentage Encrypted, with Conversion Status to confirm it's encrypting rather than decrypting. In an administrator PowerShell, Get-BitLockerVolume C: | fl shows the same information as EncryptionPercentage and VolumeStatus. Settings shows On only once encryption is complete. Microsoft says the time depends on the drive's type, size and speed, that automatic encryption can be delayed or paused while you use the PC, especially on battery, and that after a shutdown it carries on where it stopped.
