Encrypt, decrypt and verify files

Everything here is free, including encrypting several files at once and decrypting or verifying a whole folder. Encrypting a whole folder in one step is part of Clavis Pro.

Encrypt a file

Clavis lists what it's about to do and asks you to confirm.

What happens next:

  • Each file is encrypted with AES-256-GCM into a .enc file with a random name — the real name is stored inside, encrypted, so even file names don't give anything away.
  • The original is overwritten, then deleted. (On SSDs this is best effort: the drive may keep old copies of blocks out of reach of any app.)
  • To see your encrypted files by their real names, use Browse Encrypted.

Decrypt

Choose the .enc file (or a folder of them, subfolders included; that's free too), select Decrypt and press Decrypt now. The original file comes back under its real name and the .enc file is removed. If anything has been changed or damaged, Clavis refuses to decrypt it rather than give you corrupted data.

Only want to look at a file? Open it without decrypting instead (Pro).

Verify

Verify checks that .enc files are intact and open with this vault — without changing anything. It's a good habit after copying encrypted files to a USB drive or backup disk. For files someone shared with you, Verify also shows who they came from.

Tip: you can drag files and folders onto the Clavis window, or use the right-click menu in File Explorer.
