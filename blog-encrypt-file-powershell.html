How to encrypt a file using PowerShell (and what isn't built in)

You want one PowerShell command that locks a file with a password. Windows doesn't include one. Compress-Archive has no password parameter, and the built-in commands that do encrypt use your Windows account, a certificate, or protect only a stored password. Here is what each option does, with exact commands and a safe folder script.

Short answer: there is no built-in PowerShell cmdlet that encrypts a file with a password. cipher /e uses EFS, which ties files to your Windows account and isn't available on Windows Home. Protect-CmsMessage encrypts text to a certificate, and Export-Clixml saves a password that only your account on that PC can read. To lock files with a password from PowerShell, call the free 7-Zip or clavis-cli, the command line in Clavis Encrypt Premium.

None of these encrypt a whole drive. For a lost or stolen laptop, BitLocker or device encryption is a separate layer.

1. cipher /e: EFS (Pro, Enterprise and Education)

cipher is a Windows command you can run in PowerShell. /e encrypts the files or folders you name; a folder is marked so that files added to it later are encrypted too. /s: does the same for every subfolder, and /x backs up your EFS certificate and keys to a file.

Microsoft says file encryption isn't available in the Home edition. On a Windows 11 Home PC, cipher /e answered "The request is not supported." when we tried it. EFS has no password of its own: Microsoft describes it as transparent to the user who encrypted the file, so anything running as you opens it. Files can become decrypted when copied to a drive that isn't NTFS, and EFS files added to a zipped folder are unencrypted when unzipped. More in why "Encrypt contents to secure data" is greyed out.

2. Protect-CmsMessage: encrypt with a certificate (all editions)

This is the built-in answer to "PowerShell encrypt file with certificate". It uses the Cryptographic Message Syntax standard: anyone with your certificate's public key can encrypt, and only the matching private key decrypts. You need a certificate marked for document encryption first.

This worked in our test on Windows 11 Home (Windows PowerShell 5.1). Microsoft's page shows another way to make one, with certreq. notes.txt stays as it was; delete it only after Unprotect-CmsMessage gives the text back. Two limits: Unprotect-CmsMessage returns a string, so this suits text, not photos, PDFs or Office files. And the private key lives in your certificate store: without a backup of it, a new PC can't decrypt. To send to someone, encrypt with their certificate.

3. Encrypt a password to a file: Export-Clixml

For "PowerShell encrypt password to file", this is the tool. It protects a stored password, not your documents.

Microsoft says Export-Clixml encrypts credentials with the Windows Data Protection API, so "only your user account on only that computer" can decrypt them. ConvertFrom-SecureString does the same for one secure string when you give it no key. Windows PowerShell 5.1 shows a sign-in dialog for Get-Credential; PowerShell 7 asks in the console. On Linux and macOS, Export-Clixml stores the password as plain text.

4. 7-Zip from PowerShell (free, any edition)

-p with nothing after it makes 7-Zip ask for the password, so it never lands in your history. -mhe=on encrypts the file names too (.7z only). The & is PowerShell's call operator, which runs a command stored in a variable. The .7z uses AES-256. Details, quoting and extracting: 7-Zip command line password guide.

What can go wrong

  • A lost password or key means lost files. 7-Zip has no password reset. EFS files need your EFS key, so keep the cipher /x backup off the PC. CMS files need the certificate's private key. Clavis Encrypt gives you a recovery key; if you lose both it and the password, nobody can recover the files.
  • Passwords in scripts and history. Microsoft warns that plain-text passwords typed in commands "can show up in event logs and command history logs". PSReadLine saves your commands to %APPDATA%\Microsoft\Windows\PowerShell\PSReadLine; it skips lines containing words like password or secret, but 7z a -pBlue42 … contains neither. While a program runs, other programs can read its command line. Use the prompt, a DPAPI-protected file or --password-stdin.
  • Accented letters turn into "?". Windows PowerShell 5.1 pipes text to programs as ASCII unless you set $OutputEncoding, as in the script above. In our test, "ä" arrived as "?".

Questions

Can PowerShell encrypt a file with a password?

Not with a built-in cmdlet. Compress-Archive has no password parameter, cipher /e uses your Windows account rather than a password, and Protect-CmsMessage uses a certificate. To add a password, call 7-Zip (free) or clavis-cli (Clavis Encrypt Premium) from PowerShell.

How do I encrypt a file with a certificate in PowerShell?

Create a document encryption certificate (for example New-SelfSignedCertificate -Type DocumentEncryptionCert), then run Protect-CmsMessage -To with the certificate's subject, -Path and -OutFile. Unprotect-CmsMessage decrypts it. It returns text, so it suits text files rather than photos or Office documents.

How do I save an encrypted password to a file in PowerShell?

Pipe Get-Credential to Export-Clixml, and load it later with Import-Clixml. On Windows it's encrypted with DPAPI, so only your user account on that computer can read it. On Linux and macOS it's stored as plain text.

Does cipher /e work on Windows 11 Home?

No. Microsoft says file encryption isn't available in the Home edition, and on a Windows 11 Home PC cipher /e answered "The request is not supported." when we tried it. Use 7-Zip or a file-encryption app instead.

Can I decrypt an Export-Clixml password on another computer?

No. Microsoft says the exported file can't be used on a different computer or by a different user. Save the password again on each PC that needs it.

How do I encrypt every file in a folder with PowerShell?

Run 7-Zip with 7z a -p -mhe=on archive.7z and the folder, check $LASTEXITCODE, then test the archive with 7z t before you delete anything. With Clavis Encrypt Premium, clavis-cli encrypt --keep and the folder encrypts each file separately.

Is ConvertTo-SecureString encryption?

ConvertTo-SecureString only makes a secure string. ConvertFrom-SecureString turns it into an encrypted string you can save, with DPAPI or, if you pass a key, AES. On Linux and macOS, SecureString contents aren't encrypted.
