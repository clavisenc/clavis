Where is my BitLocker recovery key? How to find it on Windows 11 (and what to do if it's not in your Microsoft account)

A blue screen says BitLocker recovery and wants a long number before Windows will start. It often appears after a firmware update, a repair or a change in the PC's settings, and often on a PC whose owner never turned BitLocker on: many Windows 11 laptops, Home edition included, encrypt their drive by themselves. The number is the recovery key, made when encryption was turned on, and where it went depends on how the PC was set up. Here's where to look in each case, how to pick the right key, why it may be missing, and what to do today so this never locks you out.

Short answer: note the first 8 characters of the Key ID on the recovery screen, then on another phone or computer go to aka.ms/myrecoverykey, sign in with the Microsoft account used on the locked PC (or that of whoever set it up) and type the 48-digit key whose Key ID matches. On a work or school PC, use aka.ms/aadrecoverykey (Devices → View BitLocker Keys) or ask your IT team. Microsoft says its Support team can't retrieve, provide or recreate a lost recovery key, and there is no supported way to unlock the drive without it.

First, read the recovery screen

The screen tells you more than it seems. This applies to Windows 11 and Windows 10, Home and Pro; the two extras marked 24H2 are only on Windows 11 version 24H2 or later.

  • The Key ID is a label, not the key. It tells you which key this drive needs. Write down its first 8 characters: you'll match them in a minute.
  • The recovery key is 48 digits, in eight groups of six. It's numbers only, so you never need to type letters. Microsoft's help desk guidance says the screen checks each group of six for typing mistakes and lets you correct them.
  • Number keys don't type anything? Use the function keys: F1 to F9 type 1 to 9, and F10 types 0, as Microsoft's older BitLocker recovery guide puts it. Microsoft's BitLocker FAQ explains that the function keys work before Windows starts on every keyboard, while the number keys don't on all of them.
  • A hint about where the key is. If the key was saved to a Microsoft account, the screen shows aka.ms/myrecoverykey; from 24H2 it also shows a hint of which Microsoft account. If it was printed and saved to a file, it says Look for a printout or a text file with the key. A work PC may show a message from your IT team.
  • Why it's asking (24H2). Press Alt to open Additional recovery information, with an error category and code (for example, Secure Boot turned off, or a TPM problem).
  • Narrator and the on-screen keyboard. When the screen comes from the Windows Recovery Environment, press Windows + Ctrl + Enter for Narrator, or tap the text box for the on-screen keyboard. If the key is asked for earlier, by the Windows Boot Manager, these tools might not be available.
  • Skip this drive doesn't unlock anything. It takes you on to the recovery options (Troubleshoot and so on), and the drive stays locked.

How to pick the right key when there are several

Your account page can list several keys, for example from older PCs or other drives. Go by the Key ID, not by the order or the device name.

  1. Open aka.ms/myrecoverykey (or aka.ms/aadrecoverykey for work and school) on another device and sign in.
  2. Find the entry whose Key ID starts with the same 8 characters as the Key ID on the blue screen.
  3. Type that entry's 48-digit recovery key on the locked PC and press Enter.
  4. If no Key ID matches, this drive's key isn't in that account. Try the other accounts and places below rather than typing keys that don't match.

The key isn't in my Microsoft account: what to check

These are the reasons Microsoft documents, most likely first.

  • It's in a different account. The key goes to the Microsoft account of an administrator on the PC who signed in, or of whoever turned BitLocker on. Try every Microsoft account that has been used on that PC, including old email addresses and family members' accounts. On Windows 11 24H2 or later, the recovery screen hints at the right account.
  • The PC belongs, or once belonged, to work or school. Then the key may be in the organization's Microsoft Entra ID or Active Directory, not in your personal account. Try aka.ms/aadrecoverykey, or ask IT.
  • The PC was set up with a local account. Microsoft says device encryption isn't turned on automatically then, and a PC that uses only local accounts "remains unprotected even though the data is encrypted" until someone signs in with a Microsoft or work account. No key goes to any Microsoft account in that case, so if the PC still asks for one, BitLocker was turned on another way: look for a printout, a file or a USB drive. Our guide to turning off device encryption on Windows 11 explains how this works.
  • BitLocker was turned on by hand and saved elsewhere. On Pro, saving to the Microsoft account is only one of four choices. Look for a printout, a text file or a USB flash drive from the day it was turned on.
  • The drive came from another PC. Moving a BitLocker drive into a new computer triggers recovery. The key is wherever it was saved when the drive was first encrypted.

Also worth checking, though not from Microsoft: a password manager, your email and cloud storage (search for "recovery key"), and whoever set up or last repaired the PC.

Why Windows is asking for the key now

BitLocker asks when something it checks at startup has changed. Microsoft lists these common causes:

  • a BIOS or UEFI firmware update
  • the TPM security chip turned off, cleared or hidden in the firmware settings
  • Secure Boot turned off, or its settings changed
  • a USB stick, DVD or other bootable media connected at startup, or a changed boot order
  • docking or undocking a laptop
  • a new motherboard with a new TPM, or the drive moved into another computer
  • changes to the boot manager or the drive's partitions
  • a startup PIN entered wrongly too many times, or too many failed sign-ins on a PC where IT set a limit

Some Windows updates have also sent certain PCs to the recovery screen. For example, after the July 2024 update KB5040442, Microsoft warned that some PCs might show the BitLocker recovery screen at startup, more likely with device encryption on, and a later update addressed it. Microsoft posts issues like this as known issues in the update's support article, and lists current known issues for each Windows version on Windows release health.

If it asks at every restart: after you unlock with the key, Windows normally updates its startup checks to match the PC's current setup, so it shouldn't ask again. If it does, undo what changed. Microsoft says turning Secure Boot back on and restarting might fix it, and so might removing a bootable USB stick or disc. Then suspend and resume BitLocker once, which Microsoft says reseals the key to the PC's current setup: in Terminal (Admin) (see step 2 below), run Suspend-BitLocker -MountPoint "C:", then Resume-BitLocker -MountPoint "C:". On a work or school PC, ask IT.

If you still can't find it

  • There is no supported way around the key. Microsoft says: "Microsoft Support doesn't have the ability to retrieve, provide, or recreate a lost BitLocker recovery key."
  • Undo the change first. Turn Secure Boot and the TPM back on, undo firmware setting changes, unplug USB drives and docks, or put the drive back in its own PC. If the cause goes away, the PC may start normally.
  • Work or school PC: your IT team can usually get the key from Microsoft Entra ID or Active Directory.
  • Last resort, start again. If you can't find the key and can't undo the change, Microsoft's answer is to reset the PC using one of the Windows recovery options. It warns: "Resetting your device will remove all of your files." The catch: Microsoft also says that with BitLocker on, you need the recovery key for most recovery options in the Windows Recovery Environment, and on a PC set up with a BitLocker startup PIN or password, even a Remove everything reset asks for it. So you may have to reinstall Windows from a bootable USB drive made on another PC, which also removes everything. Files you had in OneDrive or another backup can be brought back; files that were only on this drive can't.
  • Be careful with tools or services that promise to unlock BitLocker without the key. Microsoft's own BitLocker Repair tool is for damaged drives, and it still needs the recovery key.

Do this today while your PC still works

Five minutes now saves a locked PC later. Do this before any BIOS update, repair or hardware change.

  1. Check the account (all editions, including Home). Open aka.ms/myrecoverykey and sign in with the Microsoft account you use on this PC. Note the Key IDs listed. On a work or school PC, use aka.ms/aadrecoverykey.
  2. Match it to this PC (administrator). Right-click Start (or press Windows key + X) and choose Terminal (Admin). On some PCs it's called Windows Terminal (Admin) or Windows PowerShell (Admin). Select Yes when Windows asks whether to allow changes. Run manage-bde -protectors -get C:. Under Numerical Password you'll see an ID and the 48-digit recovery password. The ID should match a Key ID in your account. To show only that entry, run manage-bde -protectors -get C: -Type RecoveryPassword. Repeat with D: and so on for other encrypted drives. If the ID isn't in your account, save the key yourself (step 3 or 5). On Windows Home, Microsoft doesn't say whether manage-bde works (we've only tested it there without administrator rights, when it refused). If it gives an error on Home, rely on step 1 and make sure your account lists a key for this PC.
  3. Back it up (Windows 11 Pro, Enterprise and Education). Select Start, type BitLocker and choose Manage BitLocker. Next to the drive, select Back up your recovery key, then choose Save to your Microsoft Account, Save to a USB flash drive, Save to a file or Print the recovery key, and select Finish. You can't save the file on the encrypted drive itself. On a work PC the first option may read Save to your Azure AD account or Save to your Microsoft Entra ID account. You can make as many backups as you like. The steps are the same on Windows 10.
  4. On Windows 11 Home there's no Manage BitLocker app: Microsoft says BitLocker isn't available on Home. Device encryption saves the key to the Microsoft account of an administrator who signs in with one, so step 1 is how you confirm it's there and copy it, and step 2 matches it to this PC if manage-bde works on yours. Settings → Privacy & security → Device encryption shows whether it's on.
  5. Keep one copy offline, away from the PC. Write the 48 digits on paper and keep them with your important papers, or store them in a password manager. Microsoft advises keeping a USB drive or printout with the key away from the computer, so not in the laptop bag.
  6. Suspend BitLocker before a BIOS or firmware update. Microsoft recommends this so the update doesn't trigger recovery. In Terminal (Admin), run Suspend-BitLocker -MountPoint "C:" -RebootCount 2, then install the update. Protection comes back by itself after two restarts; firmware updates can restart the PC more than once, and Microsoft's advice for them is a count of 2 or more, or 0. Afterwards, check that manage-bde -status C: says Protection On, and if it doesn't, run Resume-BitLocker -MountPoint "C:". A count of 0 keeps it suspended until you resume it yourself, so if you use 0, resume as soon as the update is done. The drive stays encrypted while suspended, but it isn't locked against someone who takes the PC. On Windows Home, if the command gives an error, skip the suspend and keep your key at hand for the update. Full steps: suspend instead of turning off.

Why more people see this on Windows 11 now

Since Windows 11 version 24H2, automatic device encryption no longer needs Modern Standby or HSTI-compliant hardware and is no longer blocked by DMA ports, so more PCs are encrypted after setup without their owners deciding to. If you're not sure why yours encrypted itself, see turning off device encryption on Windows 11; to find out whether it is, see how to check if your drive is encrypted.

Questions

Where is my BitLocker recovery key?

Most often in the Microsoft account used on the PC: go to aka.ms/myrecoverykey on another device, sign in and pick the key whose Key ID matches the one on the recovery screen. On a work or school PC it's at aka.ms/aadrecoverykey or with IT. If you turned BitLocker on yourself, it may be on a printout, in a text file or on a USB flash drive. If someone else set up the PC, it may be in their account.

Is the BitLocker recovery key my Microsoft password or PIN?

No. It's a 48-digit number made when encryption was turned on. Your Microsoft account password only lets you sign in to the page where the key is saved.

Can Microsoft give me my BitLocker recovery key?

No. Microsoft says its Support team can't retrieve, provide or recreate a lost BitLocker recovery key. If the key was saved to your Microsoft account, you can see it yourself at aka.ms/myrecoverykey.

Does Windows 11 Home have a BitLocker recovery key?

Yes, if device encryption is on. Windows 11 Home doesn't have the BitLocker app, but device encryption uses BitLocker and saves the recovery key to the Microsoft account an administrator signed in with. Find it at aka.ms/myrecoverykey.

Why is my computer suddenly asking for a BitLocker recovery key?

Something BitLocker checks at startup changed: often a BIOS or firmware update, Secure Boot or the TPM turned off, a USB stick or dock connected at startup, a repair that changed hardware, or the drive moved to another PC. Some Windows updates have also caused it on certain PCs, for example the July 2024 update KB5040442. On Windows 11 24H2 or later, press Alt on the recovery screen to see the reason.

Is the Key ID the recovery key?

No. The Key ID only identifies which key the drive needs. Match its first 8 characters to the Key IDs in your account, then type the 48-digit recovery key that goes with it.

How do I find my BitLocker recovery key with CMD?

While you can still sign in, right-click Start, choose Terminal (Admin) and run manage-bde -protectors -get C: (it works the same in Command Prompt run as administrator). The Numerical Password entry shows the ID and the 48-digit recovery password. This only works on a PC that starts; on the blue recovery screen you need a copy from somewhere else. On Windows Home, Microsoft doesn't say whether manage-bde works; if it gives an error, use aka.ms/myrecoverykey.

Can I find the BitLocker key without a Microsoft account?

Only if it was saved somewhere else: a printout, a text file, a USB flash drive, or a work or school account (aka.ms/aadrecoverykey or your IT team). If it was never saved anywhere you can reach, there is no supported way to get it.

What if the Key ID doesn't match any key in my account?

Then this drive's key isn't in that account. Try every other Microsoft account used on the PC, a work or school account, and any printout, file or USB drive. On Windows 11 24H2 or later, the recovery screen shows a hint of the Microsoft account that holds the key.

Does the recovery key change after I use it?

On work or school PCs it can: if IT has turned on automatic recovery password rotation, the PC makes a new key after the old one is used and stores it in Microsoft Entra ID. Microsoft doesn't describe this for personal PCs. Either way, after any recovery, check that the key in your account or on your printout still matches (manage-bde -protectors -get C: shows the current one).
